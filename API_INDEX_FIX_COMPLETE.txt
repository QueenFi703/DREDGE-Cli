🔄 HOW IT WORKS
=================

Request Flow:

  Vercel calls api/index.py:app
    ↓
  Try to load core_gateway
    ├─ If successful:
    │  ├─ Use core_gateway
    │  ├─ Add API routes
    │  └─ Serve request
    │
    └─ If fails:
       ├─ Create fallback app
       ├─ Serve from fallback
       └─ Still have all endpoints

Error Handling:

  1. Route exists & works
     → return 200 with data
  
  2. Route error
     → exception handler
     → return 500 with details
  
  3. Core gateway unavailable
     → fallback app
     → all endpoints still work
     → return 200
