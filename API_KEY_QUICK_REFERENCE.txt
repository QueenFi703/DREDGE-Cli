KEY FORMAT
==========

Structure:  orion_key_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Length:     40+ characters
Entropy:    256 bits
Example:    orion_key_7kQzPmN9vL2xJwRsT5fGhYuI8jKpOqAb


AUTHENTICATION
==============

Header:     x-api-key: <your_key>
Example:    curl -H "x-api-key: orion_key_xxx" http://127.0.0.1:8002/health
Python:     headers={"x-api-key": api_key}
JavaScript: headers: {"x-api-key": apiKey}


ENDPOINTS MATRIX
================

Endpoint              | Method | Auth      | Returns
──────────────────────┼────────┼───────────┼─────────────────────────
/                     | GET    | None      | API info
/health               | GET    | Optional  | {status, timestamp}
/invoke               | POST   | Required  | {result, usage}
/usage                | GET    | Required  | {tier, requests, limit}
/admin/keys/create    | POST   | Full*     | {key, key_id}
/admin/keys/list      | GET    | Full*     | List of keys
/admin/keys/{id}/revoke| POST   | Full*     | {status}
/admin/stats          | GET    | Full*     | {stats}
/admin/usage/{key_id} | GET    | Full*     | {usage}

* Full Access required for /admin/* endpoints


RESPONSE HEADERS (Rate Limiting)
================================

X-RateLimit-Limit:     10000
X-RateLimit-Remaining: 9850
X-RateLimit-Tier:      pro


TIERS
=====

FREE        | 100 requests/month      | For testing
STARTER     | 1,000 requests/month    | Small production
PRO         | 10,000 requests/month   | Growing apps
ENTERPRISE  | Unlimited               | Enterprise


ACCESS MODES
============

READ_ONLY:   Can read usage stats
INVOKE_ONLY: Can call /invoke
FULL_ACCESS: Everything including admin


STATUS CODES
============

200  | OK - Success
401  | Unauthorized - Missing/invalid key
403  | Forbidden - Insufficient permissions
429  | Too Many Requests - Rate limit exceeded
400  | Bad Request - Invalid input


CURL COMMANDS
=============

# Health check (no auth)
curl http://127.0.0.1:8002/health

# Health with tracking
curl -H "x-api-key: $KEY" http://127.0.0.1:8002/health

# Call /invoke
curl -X POST http://127.0.0.1:8002/invoke \
  -H "x-api-key: $KEY" \
  -H "Content-Type: application/json" \
  -d '{"input":"Hello","mode":"standard"}'

# Check usage
curl -H "x-api-key: $KEY" http://127.0.0.1:8002/usage

# Create new key (admin)
curl -X POST http://127.0.0.1:8002/admin/keys/create \
  -H "x-api-key: $ADMIN_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"Prod Key","tier":"pro","mode":"invoke_only"}'

# List keys (admin)
curl -H "x-api-key: $ADMIN_KEY" http://127.0.0.1:8002/admin/keys/list

# View stats (admin)
curl -H "x-api-key: $ADMIN_KEY" http://127.0.0.1:8002/admin/stats

# Revoke key (admin)
curl -X POST http://127.0.0.1:8002/admin/keys/key_abc123/revoke \
  -H "x-api-key: $ADMIN_KEY"


PYTHON EXAMPLES
===============

# Validate key
from api_key_manager import APIKeyStore
key_store = APIKeyStore()
metadata = key_store.validate_key("orion_key_xxx")
if metadata:
    print(f"Valid: {metadata.key_id}")

# Record usage
key_store.record_usage(
    key_id="key_abc",
    endpoint="/invoke",
    method="POST",
    response_code=200,
    duration_ms=150.0
)

# Get usage
stats = key_store.get_usage_stats("key_abc")
print(f"Usage: {stats['usage_percent']}%")

# Create key
new_key, metadata = key_store.create_key(
    name="Production",
    tier=KeyTier.PRO,
    mode=KeyMode.INVOKE_ONLY
)

# FastAPI integration
from fastapi_auth_middleware import APIKeyDependencies

deps = APIKeyDependencies(key_store, tracker)

@app.post("/invoke")
async def invoke(key = Depends(deps.verify_rate_limit)):
    return {"key_id": key.key_id}

COMMON TASKS
============

Create a new API key:
  1. Login with admin key
  2. POST /admin/keys/create
  3. Store plaintext key securely
  4. Share key_id to user

Revoke a compromised key:
  1. POST /admin/keys/{key_id}/revoke
  2. Notify user
  3. Audit logs

Check usage:
  1. GET /usage (as user)
  2. GET /admin/usage/{key_id} (as admin)

Upgrade tier:
  1. Revoke old key
  2. Create new key with higher tier
  3. Provide new key to user

Monitor activity:
  1. GET /admin/stats (overall stats)
  2. Watch for 429 responses
  3. Alert on rate limit hits


INTEGRATION PATTERN
===================

In your existing FastAPI app:

# 1. Import
from api_key_manager import init_api_key_system
from fastapi_auth_middleware import APIKeyDependencies

# 2. Initialize
key_store, tracker = init_api_key_system()
deps = APIKeyDependencies(key_store, tracker)

# 3. Add to route
@app.post("/your_endpoint")
async def endpoint(key = Depends(deps.verify_rate_limit)):
    # key is already validated
    return {"status": "ok"}

# Done! Now all requests require x-api-key header


TROUBLESHOOTING
===============

Problem: "Missing API key"
Solution: Add -H "x-api-key: ..." to curl

Problem: "Invalid API key"
Solution: Check key format (orion_key_xxx)
Solution: Check key hasn't been revoked

Problem: "429 Too Many Requests"
Solution: Check current usage: GET /usage
Solution: Upgrade tier or wait for reset (1st of month)

Problem: "403 Forbidden"
Solution: Use /admin/* endpoints only with full_access key

Problem: Test key not showing
Solution: Check terminal where you ran the app


RATE LIMIT RESET
