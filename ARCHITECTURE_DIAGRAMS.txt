┃  PIPELINE EXECUTION FLOW:                                                 ┃
┃                                                                            ┃
┃    Client                                                                  ┃
┃      │                                                                     ┃
┃      ├─ POST /api/architecture/pipeline/execute                            ┃
┃      │  {input_data: {...}, pipeline_type: "standard"}                     ┃
┃      │                                                                     ┃
┃      ▼                                                                     ┃
┃    API Layer                                                               ┃
┃      │                                                                     ┃
┃      ├─ Call dredge_run_pipeline()                                         ┃
┃      │                                                                     ┃
┃      ▼                                                                     ┃
┃    Pipeline Builder                                                        ┃
┃      │                                                                     ┃
┃      ├─ Create DAG with nodes                                              ┃
┃      ├─ Register node dependencies                                         ┃
┃      │                                                                     ┃
┃      ▼                                                                     ┃
┃    DAG Executor (async)                                                    ┃
┃      │                                                                     ┃
┃      ├─ Topological sort by dependencies                                   ┃
┃      ├─ Execute nodes in order                                             ┃
┃      │                                                                     ┃
┃      ├─ For each node:                                                     ┃
┃      │  ├─ Check cache (Redis → Local)                                     ┃
┃      │  ├─ If miss: Execute node                                           ┃
┃      │  ├─ Store in cache                                                  ┃
┃      │  └─ Log telemetry                                                   ┃
┃      │                                                                     ┃
┃      ▼                                                                     ┃
┃    Collect Results                                                         ┃
┃      │                                                                     ┃
┃      ├─ node_results: {node_id: result, ...}                               ┃
┃      ├─ execution_log: [event, event, ...]                                 ┃
┃      ├─ telemetry: {metrics, events}                                       ┃
┃      │                                                                     ┃
┃      ▼                                                                     ┃
┃    Format Response                                                         ┃
┃      │                                                                     ┃
┃      └─ Return to client ✓                                                 ┃
┃                                                                            ┃
┃  ─────────────────────────────────────────────────────────────────────    ┃
┃                                                                            ┃
┃  TRANSLATION WITH FAILOVER:                                               ┃
┃                                                                            ┃
┃    Client Request                                                          ┃
┃      │                                                                     ┃
┃      ├─ translate("Hello", "en", "es")                                     ┃
┃      │                                                                     ┃
┃      ▼                                                                     ┃
┃    ProviderChain                                                           ┃
┃      │                                                                     ┃
┃      ├─ Try Primary: GoogleProvider                                        ┃
┃      │  ├─ Success → Return result ✓                                       ┃
┃      │  │  Metrics: latency=150ms, cache_hit=false                         ┃
┃      │  │                                                                   ┃
┃      │  └─ Failure → Increment counter                                     ┃
┃      │                                                                     ┃
┃      ├─ Try Fallback 1: DeepProvider                                       ┃
┃      │  ├─ Success → Return result ✓                                       ┃
┃      │  │  Metrics: latency=245ms, fallback_used=true                      ┃
┃      │  │                                                                   ┃
┃      │  └─ Failure → Increment counter                                     ┃
┃      │                                                                     ┃
┃      └─ All Failed → Raise exception                                       ┃
┃         Circuit breaker: Mark provider UNHEALTHY after 5x                  ┃
┃                                                                            ┃
┃      ▼                                                                     ┃
┃    Return to Client                                                        ┃
┃      ├─ Status: success | error                                            ┃
┃      ├─ Provider used: "google" | "deep" | failed                          ┃
┃      ├─ Result: translated text                                            ┃
┃      └─ Execution history: [attempt1, attempt2, ...]                       ┃
