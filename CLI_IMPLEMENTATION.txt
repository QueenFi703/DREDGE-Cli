🎯 CLI FEATURES
═════════════════

1. COMMAND STRUCTURE
   ═════════════════

   dredge [OPTIONS] COMMAND [ARGS]

   Main Commands:
   - pipeline      Execute DREDGE pipeline
   - translate     Translate text
   - analyze       Semantic analysis
   - status        System status
   - config        Configuration management
   - interactive   Interactive mode
   - version       Show version


2. PIPELINE COMMAND
   ═════════════════

   Execute:
     dredge pipeline -q "query text"
     dredge pipeline input.json
     dredge pipeline --pipeline-type standard -q "test"

   Options:
     -p, --pipeline-type    standard | ios_swift
     -q, --query           Query text
     INPUT_FILE            JSON input file

   Output:
     - Result data
     - Execution log
     - Telemetry summary
     - DAG graph


3. TRANSLATE COMMAND
   ═════════════════

   Execute:
     dredge translate "Hello world"
     dredge translate "Bonjour" -s fr -t en
     dredge translate "你好" -s zh -t en

   Options:
     -s, --source LANG     Source language (default: en)
     -t, --target LANG     Target language (default: es)

   Output:
     - Translated text
     - Provider used
     - Confidence
     - Execution history


4. ANALYZE COMMAND
   ════════════════

   Execute:
     dredge analyze "What is AI?"
     dredge analyze "Explain quantum computing"
     dredge analyze "Quantum physics" --context context.json

   Options:
     --context, -c         Context file (JSON)

   Output:
     - Analysis results
     - Intent detection
     - Entity extraction
     - Sentiment
     - Provider used


5. STATUS COMMAND
   ═══════════════

   Execute:
     dredge status
     dredge status --json
     dredge status -v

   Shows:
     - Provider health (HEALTHY/DEGRADED/UNHEALTHY)
     - Success rates
     - Average latency
     - Cache status
     - Consecutive failures


6. CONFIG COMMAND
   ═══════════════

   Execute:
     dredge config --no-cache
     dredge config --pipeline-type ios_swift
     dredge config --log-level DEBUG

   Options:
     --cache / --no-cache              Enable/disable caching
     --pipeline-type TYPE              Default pipeline
     --log-level LEVEL                 Log level (DEBUG/INFO/WARNING/ERROR)

   Stores in:
     ~/.dredge/config.json


7. INTERACTIVE MODE
   ═════════════════

   Enter:
     dredge interactive

   Interactive Commands:
     pipeline [query]      Execute pipeline
     translate [text]      Translate text
     analyze [query]       Analyze query
     status                Show status
     config                Show configuration
     help                  Show help
     exit                  Exit

   Example Session:
     > pipeline what is machine learning?
     ▶ Executing DREDGE Pipeline...
     ✓ Pipeline completed
     [results displayed]

     > translate Hello
     ▶ Translating: en → es...
     ✓ Translation complete
     [results displayed]

     > status
     ▶ Checking system status...
     [status displayed]

     > exit
     Goodbye!

🔧 CONFIGURATION
═════════════════

1. CONFIG FILE
   ════════════

   Location: ~/.dredge/config.json

   Example:
   {
     "cache_enabled": true,
     "pipeline_type": "standard",
     "log_level": "INFO",
     "output_format": "table",
     "timeout": 30
   }


2. ENVIRONMENT VARIABLES
   ══════════════════════

   DREDGE_PIPELINE_TYPE=standard
   DREDGE_LOG_LEVEL=INFO
   DREDGE_CACHE_ENABLED=true
   DREDGE_OUTPUT_FORMAT=table
   DREDGE_TIMEOUT=30


3. COMMAND-LINE OPTIONS
   ═══════════════════════

   Global Options:
     -v, --verbose           Verbose output
     -j, --json              JSON output format
     -c, --config-file       Config file path

   Command Options:
     dredge pipeline --pipeline-type ios_swift
     dredge translate -s en -t es
     dredge analyze --context context.json
     dredge config --log-level DEBUG
