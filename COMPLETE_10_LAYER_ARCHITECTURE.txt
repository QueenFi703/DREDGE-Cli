📊 EXECUTION FLOW
═════════════════

User Request (REST or CLI):
  ↓
dredge_run_pipeline(input_data)
  ↓
Create pipeline (standard/ios_swift)
  ↓
IngestNode: Normalize input
  ↓
DAGExecutionEngine: Orchestrate execution
  ↓
ModeBranchNode: Branch by mode
  ↓
TranslateNode: Format translation
  ↓
NormalizeNode: Data validation + fallback providers
  ↓
Check cache (Redis/local)
  ↓
Execute provider chain:
  └─ Try primary provider
     └─ On failure: try fallback providers
        └─ On all failure: raise exception
  ↓
Store in cache (Redis + local)
  ↓
Telemetry logging
  ↓
Return results + telemetry + execution log


🔗 PROVIDER FAILOVER MECHANISM
═════════════════════════════════

Request: Translate "Hello"

1. Primary: GoogleProvider
   └─ Success: Return result, log metrics
   
2. If GoogleProvider fails (latency/timeout/error):
   └─ Increment failure counter
   └─ Try Fallback: DeepProvider
   └─ Success: Return result, log fallback event
   
3. If all fail:
   └─ Log all failures
   └─ Circuit breaker activates after 5 consecutive failures
   └─ Return error with execution history

Metrics Tracked:
  - Provider: name, type, status
  - Requests: total, successful, failed
  - Performance: avg_latency_ms, cache_hit_rate
  - Health: status, consecutive_failures, is_available


💾 CACHING STRATEGY
═════════════════════

Cache Key Generation:
  MD5(pipeline_id + node_id + input_data)
  └─ Deterministic and collision-resistant

Storage:
  1. Redis (primary)
     - Distributed, persistent
     - TTL: 3600s
     - Cross-process access

  2. Local (fallback)
     - In-memory
     - Process-specific
     - Instant access

Cache Workflow:
  Request arrives
  ├─ Check Redis
  │  ├─ Hit: Return cached result, mark CACHED
  │  └─ Miss: Continue
  ├─ Check local cache
  │  ├─ Hit: Return cached result, mark CACHED
  │  └─ Miss: Continue
  ├─ Execute node
  ├─ Store in Redis (with TTL)
  ├─ Store in local cache
  └─ Return result


📈 METRICS & TELEMETRY
═══════════════════════

Per Provider:
  - total_requests: count
  - successful_requests: count
  - failed_requests: count
  - success_rate: % (calculated)
  - avg_latency_ms: float
  - cache_hit_rate: % (calculated)
  - consecutive_failures: count
  - status: HEALTHY | DEGRADED | UNHEALTHY

Per Pipeline:
  - pipeline_id: unique
  - status: PENDING | RUNNING | COMPLETED | FAILED
  - start_time: timestamp
  - end_time: timestamp
  - duration: milliseconds

Per Node:
  - node_id: name
  - node_type: INGEST | TRANSLATE | NORMALIZE | EXECUTE | CACHE
  - status: PENDING | RUNNING | COMPLETED | FAILED | CACHED
  - start_time: timestamp
  - end_time: timestamp
  - duration: milliseconds
  - cache_hit: boolean
  - error: error message (if any)

Events Logged:
  - pipeline_start: timestamp, pipeline_id
  - node_executed: node_id, status, duration, cache_hit
  - cache_hit: node_id, cache_key
  - cache_miss: node_id
  - provider_attempt: provider_name, attempt_number
  - provider_success: provider_name, latency
  - provider_failure: provider_name, error
  - pipeline_complete: pipeline_id, total_duration
