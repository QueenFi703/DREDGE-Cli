📊 ARCHITECTURE
=================

The Core Gateway:
  ONE FastAPI application
    ├─ Adapter Registry (manages all adapters)
    ├─ Adapter 1: Studio (Web UI)
    ├─ Adapter 2: Auth (API Keys)
    ├─ Adapter 3: Health (Monitoring)
    └─ Adapter 4: Admin (Operations)

Entry Points:
  Primary: core_gateway.py:app
  Deployment: api/deployment.py:app (for Vercel)

How it works:
  1. Core Gateway starts (single FastAPI instance)
  2. Adapter Registry created
  3. Each adapter mounted via include_router()
  4. Adapter failures isolated (don't crash gateway)
  5. All routes accessible via single port

🔧 EXTEND WITH NEW ADAPTERS
=============================

Create a new adapter:

  def create_my_new_feature():
      from fastapi import APIRouter
      
      router = APIRouter(prefix="/myfeature", tags=["MyFeature"])
      
      @router.get("/status")
      async def status():
          return {"status": "operational", "feature": "active"}
      
      return router

Add to core_gateway.py mount_adapters():

  try:
      my_router = create_my_new_feature()
      app.include_router(my_router)
      adapter_registry.register(
          "MyFeature",
          enabled=True,
          description="My new feature"
      )
  except Exception as e:
      logger.warning(f"Failed to mount MyFeature: {e}")
      adapter_registry.register(
          "MyFeature",
          enabled=False,
          description="Failed"
      )

That's it! Your new adapter is now mounted and accessible.
