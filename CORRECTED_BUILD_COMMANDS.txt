⚠️ THE ISSUE
============
Error: "pip install build twine" fails with "not a Python project"
Cause: You need to BE IN the dredge-cli-repo directory FIRST


✅ CORRECTED COMMANDS
====================

ALL COMMANDS IN ONE BLOCK (Copy & Paste This):

```bash
# Step 1: Navigate to the correct directory
cd dredge-cli-repo

# Step 2: Upgrade pip first
python -m pip install --upgrade pip

# Step 3: Install build dependencies
python -m pip install --upgrade setuptools wheel

# Step 4: Install packaging tools
python -m pip install build twine

# Step 5: Clean old builds (if any)
rm -rf build dist *.egg-info

# Step 6: Build the package
python -m build

# Step 7: Verify the build
twine check dist/*

# Step 8a: Test on TestPyPI (optional)
twine upload --repository testpypi dist/*

# Step 8b: Upload to production PyPI
twine upload dist/*
```


INDIVIDUAL COMMANDS (One at a time):
===================================

Command 1 - Go to project directory:
cd dredge-cli-repo

Command 2 - Upgrade pip:
python -m pip install --upgrade pip

Command 3 - Install build tools (THIS WILL NOW WORK):
python -m pip install build twine

KEY DIFFERENCES:
===============

❌ WRONG (causes "not a Python project"):
pip install build twine
(run from outside dredge-cli-repo directory)

✅ CORRECT:
cd dredge-cli-repo
python -m build
(uses module execution, works from anywhere once in directory)

❌ WRONG:
python setup.py bdist_wheel
(old method, deprecated)

✅ CORRECT:
python -m build
(new PEP 517/518 standard)

PYPI CREDENTIALS:
================

Before uploading, you need PyPI credentials.

Option 1: Create ~/.pypirc file
cat > ~/.pypirc << EOF
[pypi]
username = __token__
password = pypi-AgEIcHlwaS5vcmc...
EOF

Option 2: Use environment variable
export TWINE_PASSWORD="pypi-AgEIcHlwaS5vcmc..."

Option 3: Interactive prompt
twine upload dist/*
# Twine will ask for credentials

TROUBLESHOOTING:
================

Error: "python: command not found"
Fix: Use "python3" instead on Linux/Mac

Error: "No module named 'build'"
Fix: Make sure you ran "python -m pip install build"

Error: "'build' is not recognized as a Python project"
Fix: Make sure you're IN dredge-cli-repo directory first

Error: "setup.py not found"
Fix: Check you're in right directory:
     pwd (or cd on Windows)
     Should show: .../dredge-cli-repo

Error: "twine: command not found"
Fix: Run: python -m pip install twine

Error: "401 Unauthorized"
Fix: Check PyPI token - regenerate at pypi.org/manage/account/tokens/
