✅ DETAILED STEP-BY-STEP (WITH EXPLANATIONS)
=============================================

STEP 1: Open terminal and navigate to project
─────────────────────────────────────────────
Command:
  cd dredge-cli-repo

What it does:
  Changes your current directory to dredge-cli-repo
  This is WHERE the setup.py and pyproject.toml files are located

Verification:
  ls setup.py
  (should show: setup.py)


STEP 2: Upgrade pip (package installer)
───────────────────────────────────────
Command:
  python -m pip install --upgrade pip

What it does:
  Makes sure you have the latest version of pip
  Ensures compatibility with modern packages

What -m means:
  "Run pip as a Python module"
  This is the recommended way instead of just "pip"


STEP 3: Install build tools
──────────────────────────
Command:
  python -m pip install build twine

What it does:
  Installs 'build' - creates distribution files
  Installs 'twine' - uploads to PyPI
  
Why "python -m pip" works but "pip" might not:
  You're running it through Python's module system
  This ensures it installs to the right location


STEP 4: Clean old builds (if any)
──────────────────────────────────
Command:
  rm -rf build dist *.egg-info

What it does:
  Removes old package files
  Ensures clean build

On Windows, use:
  rmdir /s /q build dist
  (or just delete the folders manually)


STEP 5: Build the distribution
──────────────────────────────
Command:
  python -m build

What it does:
  Creates two files:
    1. dist/dredge-studio-2.0.0.tar.gz (source distribution)
    2. dist/dredge_studio-2.0.0-py3-none-any.whl (wheel)
  
  These are what get uploaded to PyPI

Output should show:
  * Creating venv isolated environment...
  * Installing packages in isolated environment...
  * Building wheel...
  * Created dist/dredge_studio-2.0.0-py3-none-any.whl
  * Building sdist...
  * Created dist/dredge-studio-2.0.0.tar.gz
  Successfully built dredge-studio-2.0.0.tar.gz and dredge_studio-2.0.0-py3-none-any.whl


STEP 6: Verify the build
───────────────────────
Command:
  twine check dist/*

What it does:
  Checks that the package is valid
  Ensures metadata is correct
  Verifies README renders properly

Expected output:
  Checking dist/dredge_studio-2.0.0-py3-none-any.whl: Passed ✓
  Checking dist/dredge-studio-2.0.0.tar.gz: Passed ✓

📋 COMMON ERRORS & FIXES
========================

Error 1: "python: command not found"
──────────────────────────────────
Solution: Use "python3" on Linux/Mac
Command: python3 -m pip install build twine

Error 2: "'build' is not recognized as a Python project"
─────────────────────────────────────────────────────
Solution: You're NOT in dredge-cli-repo directory
Fix:
  pwd  (check current directory)
  cd dredge-cli-repo  (navigate there)
  ls setup.py  (verify setup.py exists)

Error 3: "ModuleNotFoundError: No module named 'build'"
─────────────────────────────────────────────────────
Solution: build wasn't installed properly
Fix:
  python -m pip install --upgrade build
  python -m build

Error 4: "setup.py not found"
──────────────────────────────
Solution: Wrong directory
Fix:
  cd dredge-cli-repo
  ls setup.py  (verify it exists)

Error 5: "twine: command not found"
───────────────────────────────────
Solution: twine not installed
Fix:
  python -m pip install twine
  python -m twine upload dist/*

Error 6: "401 Unauthorized" during upload
──────────────────────────────────────────
Solution: Invalid PyPI credentials
Fix:
  1. Go to https://pypi.org/manage/account/tokens/
  2. Delete old token
  3. Create new token
  4. Update .pypirc or TWINE_PASSWORD
