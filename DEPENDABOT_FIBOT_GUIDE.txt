LIVE ENDPOINTS (15+)
====================

Alert Management:
  GET  /api/dependabot/alerts
       - Returns: All alerts with summary stats
       - Query: ?state=open|dismissed|all
       
  GET  /api/dependabot/alerts/<id>
       - Returns: Detailed alert information
       
  POST /api/dependabot/alerts/<id>/dismiss
       - Body: {"reason": "tolerable_risk", "comment": "..."}
       
  POST /api/dependabot/alerts/<id>/reopen
       - Reopens dismissed alerts

FiBot Analysis (AI-Powered):
  GET  /api/dependabot/alerts/<id>/analyze
       - Returns: FiBot security analysis with:
         * Vulnerability assessment
         * Risk factors
         * Remediation steps
         * Confidence score
         
  GET  /api/dependabot/recommendations
       - Returns: FiBot recommendations sorted by priority
       - Fields: alert_id, package, severity, fibot_recommendation, priority_score
       
  GET  /api/dependabot/fibot/status
       - Returns: FiBot operational status
       
  POST /api/dependabot/fibot/chat
       - Body: {"question": "Your security question"}
       - Returns: Answer with confidence score

Vulnerability Data:
  GET  /api/dependabot/vulnerabilities
       - Returns: Vulnerability breakdown by:
         * Type (supply_chain, code_execution, etc.)
         * Severity (critical, high, medium, low)
         * Trends (past week/month/quarter)
       
  GET  /api/dependabot/stats
       - Returns: Comprehensive statistics:
         * Total, open, dismissed, fixed alerts
         * Packages affected
         * Severity breakdown
         * FiBot status
