PRODUCTION INTEGRATION PATH
===========================

Step 1: Add GitHub Token
  export GITHUB_TOKEN="ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxx"

Step 2: Update to use real API:
  Modify dependabot_alerts.py to use GitHubDependabotClient
  
Step 3: Connect to real repos:
  GET /api/dependabot/alerts/owner/repo-name
  
Step 4: Enable webhooks:
  Configure GitHub repo → Settings → Webhooks
  POST to /api/dependabot/webhook

Step 5: Deploy to production:
  Use production WSGI server (Gunicorn, uWSGI)
  Connect to database for persistence
  Set up monitoring and alerting
