════════════════════════════════════════════════════════════════════════════════
                    REGISTER CUSTOM DOMAIN (api.dredge.ai)
════════════════════════════════════════════════════════════════════════════════

STEP 1: Register Domain
   Provider: Namecheap, GoDaddy, or Google Domains
   Domain: api.dredge.ai
   Cost: ~$10/year
   Duration: ~5 minutes

STEP 2: Point DNS to Your Host
   
   IF USING VERCEL:
   ────────────────
   Go to: Vercel Dashboard → Project Settings → Domains
   Click: "Add Domain"
   Enter: api.dredge.ai
   Vercel shows DNS records to add
   Go to your registrar and add CNAME:
     CNAME api.dredge.ai → cname.vercel.com
   
   IF USING RAILWAY:
   ─────────────────
   Go to: Railway Dashboard → Project Settings → Domains
   Click: "Add Custom Domain"
   Enter: api.dredge.ai
   Railway shows CNAME target
   Add to registrar DNS

STEP 3: Wait for DNS
   DNS propagation: 5 minutes to 24 hours
   Check: https://whatsmydns.net/?d=api.dredge.ai

STEP 4: Update GitHub OAuth
   GitHub Settings → Developer settings → OAuth Apps
   Edit DREDGE OAuth App:
   
   Authorization callback URL:
   https://api.dredge.ai/auth/github/callback
   
   Homepage URL:
   https://api.dredge.ai

════════════════════════════════════════════════════════════════════════════════
                         TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

DEPLOYMENT FAILS:
1. Check environment variables are set
2. Check GitHub OAuth credentials are correct
3. Check Dockerfile.railway is in repo
4. Check wsgi.py is in repo root

BUILD FAILS:
1. Check Python version (should be 3.10)
2. Check requirements.txt exists
3. Look at build logs in Vercel/Railway dashboard

APP CRASHES AFTER DEPLOY:
1. Check logs in Vercel/Railway dashboard
2. Verify OAUTH_REDIRECT_BASE is set correctly
3. Verify GITHUB_CLIENT_ID and GITHUB_CLIENT_SECRET are correct
4. Check SECRET_KEY is set

GITHUB OAUTH NOT WORKING:
1. Check GitHub OAuth app exists at:
   GitHub Settings → Developer settings → OAuth Apps
2. Verify redirect URL matches your deployed URL
3. Verify Client ID and Secret are correct
