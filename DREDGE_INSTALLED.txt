💻 HOW TO USE DREDGE
====================

Import in Python:
─────────────────

# Import main module
import dredge

# Import specific components
from dredge import server
from dredge import advanced_features
from dredge import dependabot_alerts
from dredge import string_theory

# Advanced features
from dredge.advanced_features import dredge_advanced

# FiBot security
from dredge.dependabot_alerts import FiBotSecurityAnalyzer

# String theory
from dredge.string_theory import StringTheory


Run the Server:
───────────────

# Start Flask server
python -m dredge.server

# Or use the installed command
dredge-server

# Or use the advanced server
dredge-advanced


CLI Commands:
─────────────

# Check what's available
python -m dredge --help

# Run the CLI
python -m dredge


Example Usage:
──────────────

import dredge.advanced_features as af
from dredge.dependabot_alerts import FiBotSecurityAnalyzer

# Create FiBot analyzer
fibot = FiBotSecurityAnalyzer()

# Analyze a vulnerability
analysis = fibot.analyze_vulnerability(
    package="Flask",
    severity="high",
    cve_details={"id": "CVE-2023-1234"}
)

print(analysis)
