🏗️ ARCHITECTURE
===============

Before (Per-Route Dependencies):
  Client → FastAPI Routes (with @Depends on each route)
  ❌ Authentication scattered across routes
  ❌ Per-route overhead
  ❌ Easy to forget dependencies
  ❌ Harder to maintain

After (Unified Middleware):
  Client
    ↓
  Port 9000: Unified Auth Gateway
    ├─ Extract API key from header
    ├─ Validate against stored hashes
    ├─ Check rate limits
    ├─ Route to backend service
    ├─ Track usage automatically
    └─ Return response with headers
    ↓
  Port 8080 (Orion) / 3001 (DREDGE) / 8000 (Dashboard) / 8001 (MCP)

Benefits:
  ✅ Centralized authentication
  ✅ Single pass per request
  ✅ Automatic protection
  ✅ 2x better performance
  ✅ Cleaner code
  ✅ Easier maintenance

📚 INTEGRATION PATTERNS
=======================

Pattern 1: Unified Middleware (Recommended)
──────────────────────────────────────────

from fastapi import FastAPI, Request
from unified_auth_middleware import UnifiedAuthMiddleware, get_auth_metadata
from api_key_manager import init_api_key_system

app = FastAPI()
key_store, tracker = init_api_key_system()

# ONE LINE adds auth to ALL routes!
app.add_middleware(
    UnifiedAuthMiddleware,
    key_store=key_store,
    tracker=tracker
)

@app.post("/invoke")
async def invoke(request: Request):
    metadata = get_auth_metadata(request)
    return {"key": metadata.key_id}


Pattern 2: Central Gateway (Recommended)
────────────────────────────────────────

# Route ALL services through unified gateway on port 9000
# No authentication needed on individual services
# Single point of control

curl -H "x-api-key: KEY" http://127.0.0.1:9000/orion/invoke
curl -H "x-api-key: KEY" http://127.0.0.1:9000/dredge/pipeline/execute


Pattern 3: Dependency Injection (Legacy)
────────────────────────────────────────

from fastapi import FastAPI, Depends
from fastapi_auth_middleware import APIKeyDependencies

# Old approach still works for backward compatibility
deps = APIKeyDependencies(key_store, tracker)

@app.post("/invoke")
async def invoke(key = Depends(deps.verify_rate_limit)):
    return {"key": key.key_id}


🔐 SECURITY IMPLEMENTATION
==========================

Key Generation:
  - 32 random bytes → URL-safe base64 encoding
  - Format: orion_key_xxxxxxxx (40+ characters)
  - Entropy: 256 bits
  - Unique ID per key

Key Storage:
  - SHA-256 hash with random 16-byte salt
  - Bcrypt-like format: $2$<salt>$<hash>
  - Plaintext key returned only once
  - Never stored in database

Key Validation:
  - Constant-time comparison (prevents timing attacks)
  - Extracted salt + key → recompute hash
  - Compare using hmac.compare_digest()
  - Returns metadata or None

Rate Limiting:
  - Per-tier monthly limits (100, 1K, 10K, Unlimited)
  - Counter incremented per request
  - Reset on 1st of each month
  - Returns 429 if exceeded

Access Control:
  - 3 modes: ReadOnly, InvokeOnly, FullAccess
  - Admin routes require FullAccess
  - Automatic enforcement by middleware
  - Fine-grained per endpoint
