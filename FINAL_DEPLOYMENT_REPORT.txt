🛠️  TROUBLESHOOTING COMMON ISSUES
==================================

Issue 1: Vercel can't find entry point
  Error: "Function entry point is invalid"
  Solution:
    1. Verify api/gateway.py exists
    2. Check it exports 'app'
    3. Confirm pyproject.toml entrypoint = "api/gateway:app"
    4. Run: git push origin master
    5. Run: vercel --prod --force

Issue 2: Module import errors
  Error: "ModuleNotFoundError: No module named 'unified_auth_gateway'"
  Solution:
    1. Verify requirements.txt has all dependencies
    2. Check unified_auth_gateway.py exists in root
    3. Ensure api/gateway.py adds parent path: sys.path.insert(0, str(Path(__file__).parent.parent))

Issue 3: SSL certificate not ready
  Error: "SSL certificate problem" or "trust relationship error"
  Solution:
    1. Wait 5-10 minutes for Let's Encrypt provisioning
    2. Check Vercel dashboard for status
    3. Try curl -k https://... (skip certificate validation)
    4. Or use http:// for immediate testing

Issue 4: Health endpoint returns 500
  Error: "Internal server error"
  Solution:
    1. Check Vercel logs: vercel logs <url>
    2. Verify unified_auth_gateway.py is correct
    3. Check api_key_manager.py can be imported
    4. Ensure /tmp directory is writable
