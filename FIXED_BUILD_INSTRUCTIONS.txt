✅ MANUAL METHOD - Step by Step
===============================

Step 1: Navigate to project
  cd dredge-cli-repo

Step 2: Install tools
  python -m pip install --upgrade pip setuptools wheel build twine

Step 3: Clean old builds
  rm -rf build dist *.egg-info

Step 4: Build
  python -m build

Step 5: Check dist folder
  dir dist
  (or: ls -la dist/ on Linux/Mac)

Expected output:
  dist/dredge_studio-2.0.0-py3-none-any.whl
  dist/dredge-studio-2.0.0.tar.gz

Step 6: Upload to PyPI
  twine upload dist/*


✅ ONE-LINER METHOD
===================

From root directory:

```
cd dredge-cli-repo && python -m pip install build twine && python -m build && twine upload dist/*
```

❌ TROUBLESHOOTING
==================

Error: "Invalid distribution"
Fix: Run: python simple_build.py (handles all issues)

Error: "twine: command not found"  
Fix: python -m pip install twine

Error: "setup.py not found"
Fix: cd dredge-cli-repo (then run commands)

Error: "No files in dist/"
Fix: python -m build (must be in dredge-cli-repo)

Error: "401 Unauthorized"
Fix: Check PyPI token, regenerate at pypi.org
