📋 MIGRATION DETAILS
====================

Route Conversions:

Flask:
  @app.route('/')
  def index():
      return jsonify({...})

FastAPI:
  @app.get("/")
  async def index():
      return {...}

---

Flask:
  @app.route('/api/dredge/lift', methods=['POST'])
  def lift_insight():
      data = request.get_json()
      return jsonify({...})

FastAPI:
  @app.post("/api/dredge/lift")
  async def lift_insight(request: InsightRequest):
      return InsightResponse(...)

---

Flask Error Handling:
  @app.errorhandler(404)
  def not_found(error):
      return jsonify({"error": "..."}), 404

FastAPI Error Handling:
  @app.exception_handler(404)
  async def not_found_handler(request, exc):
      return JSONResponse(status_code=404, content={...})


Model Validation:

Flask:
  # Manual validation in route
  data = request.get_json()
  if not data or 'insight' not in data:
      return error

FastAPI:
  # Automatic validation with Pydantic
  class InsightRequest(BaseModel):
      insight: str
  
  @app.post("/api/dredge/lift")
  async def lift_insight(request: InsightRequest):
      # request.insight is already validated

📊 ASGI vs WSGI
================

WSGI (Flask):
  - Synchronous only
  - Request-response blocking
  - Not suitable for async operations
  - Traditional web servers (Gunicorn)

ASGI (FastAPI):
  - Async/await support
  - Non-blocking I/O
  - WebSocket support
  - Modern servers (Uvicorn, Hypercorn)
  - Vercel native support

Benefits for Vercel:
  ✅ Serverless-optimized
  ✅ Fast cold starts
  ✅ Efficient resource usage
  ✅ Built-in async support

FastAPI:

Status: 100% compatible


Dashboard Route:

Flask:
  @app.route('/dashboard')
  def dashboard():
      html_file = static_dir / 'dashboard_combined.html'
      if html_file.exists():
          return send_file(str(html_file), mimetype='text/html')
      return jsonify({"error": "..."}), 404

FastAPI:
  @app.get("/dashboard")
  async def dashboard():
      html_file = static_dir / 'dashboard_combined.html'
      if html_file.exists():
          return FileResponse(str(html_file), media_type='text/html')
      raise HTTPException(status_code=404, detail="...")

Status: 100% compatible


Insight Lifting (with validation):

Flask:

FastAPI:
  class InsightRequest(BaseModel):
      insight: str
  
  @app.post("/api/dredge/lift")
  async def lift_insight(request: InsightRequest):
      # Validation automatic

      return InsightResponse(...)
