🎯 GITHUB LOGIN FLOW
====================

When user clicks "Sign in with GitHub":

1. Browser redirected to GitHub:
   https://github.com/login/oauth/authorize?...

2. User authorizes DREDGE Studio app

3. GitHub redirects back to:
   http://localhost:3000/auth/github/callback?code=...

4. Server exchanges code for access token

5. Server fetches user info from GitHub API

6. User session created

7. Redirect to dashboard

8. User logged in!
