🔗 GORDON API ENDPOINTS
════════════════════════

New endpoints (prefix: /api/gordon):

1. GET /api/gordon/health
   ──────────────────────────
   Get bridge health status

   Response:
   {
     "status": "success",
     "bridge": {
       "status": "operational",
       "gordon": "healthy",
       "dredge": "healthy",
       "bridge_running": true
     }
   }


2. POST /api/gordon/start
   ───────────────────────
   Start Gordon bridge

   Body:
   {
     "gordon_url": "http://gordon:8000",
     "dredge_url": "http://dredge:3001"
   }

   Response:
   {
     "status": "success",
     "message": "Gordon bridge started"
   }


3. POST /api/gordon/stop
   ──────────────────────
   Stop Gordon bridge

   Response:
   {
     "status": "success",
     "message": "Gordon bridge stopped"
   }


4. POST /api/gordon/task/execute
   ───────────────────────────────
   Execute a task from Gordon

   Body:
   {
     "task_id": "task_123",
     "title": "Translate text",
     "type": "translate",
     "input_data": {
       "text": "Hello",
       "source_language": "en",
       "target_language": "es"
     },
     "priority": 5
   }

   Response:
   {
     "status": "success",
     "task_id": "task_123",
     "execution_status": "success",
     "result": {...},
     "duration": 0.234
   }


5. GET /api/gordon/capabilities
   ─────────────────────────────
   Advertise DREDGE capabilities to Gordon

   Response:
   {
     "agent": "DREDGE",
     "capabilities": [
       {
         "name": "pipeline_execution",
         "endpoint": "/api/architecture/pipeline/execute"
       },
       {
         "name": "text_translation",
         "endpoint": "/api/architecture/translate"
       },
       {
         "name": "semantic_analysis",
         "endpoint": "/api/architecture/analyze"
       }
     ]
   }


6. GET /api/gordon/status
   ───────────────────────
   Get detailed bridge status

   Response:
   {
     "status": "success",
     "bridge": {
       "status": "operational",
       "gordon": "healthy",
       "dredge": "healthy"
     }
   }


🔄 TASK FLOW
═════════════

1. Gordon sends task:
   {
     "task_id": "task_abc123",
     "type": "translate",
     "input_data": {"text": "Hello", "target_language": "es"}
   }

2. DREDGE bridge receives and routes:
   - Task type: translate
   - Call: /api/architecture/translate

3. DREDGE executes:
   - Provider chain
   - Multi-provider failover
   - Caching
   - Telemetry

4. Result returned:
   {
     "task_id": "task_abc123",
     "status": "success",
     "result": {"translated": "Hola", "provider": "google"},
     "duration": 0.245
   }

5. Gordon receives result and routes to next agent or client

🛠️ BRIDGE COMPONENTS
═════════════════════

1. GordonClient
   ─────────────
   - Async HTTP client to Gordon
   - Registration with Gordon
   - Task polling
   - Result submission

2. GordonTask
   ──────────
   Dataclass for tasks from Gordon:
   - task_id: unique identifier
   - title: human-readable title
   - type: task type (pipeline, translate, analyze)
   - input_data: task parameters
   - priority: 1-10 (higher = more important)
   - status: pending, running, completed, failed

3. GordonResult
   ─────────────
   Dataclass for results to Gordon:
   - task_id: corresponding task
   - status: success, error, partial
   - result: execution result
   - duration: execution time (ms)
   - error: error message (if failed)

4. GordonDREDGEBridge
   ──────────────────
   Main bridge orchestrator:
   - Registers with Gordon
   - Listens for tasks
   - Routes to DREDGE endpoints
   - Returns results
   - Health monitoring


📊 BRIDGE LIFECYCLE
══════════════════

1. INITIALIZATION
   - Create GordonDREDGEBridge instance
   - Configure Gordon URL
   - Configure DREDGE URL

2. REGISTRATION
   - Call /api/agents/register on Gordon
   - Advertise capabilities
   - Get session_id

3. LISTENING
   - Poll /api/tasks/next on Gordon
   - Wait for incoming tasks

4. EXECUTION
   - Receive task from Gordon
   - Route to DREDGE endpoint
   - Execute with caching, telemetry
   - Wait for completion

5. RESULT DELIVERY
   - Send result back to Gordon
   - Include execution metrics
   - Handle errors gracefully

6. SHUTDOWN
   - Close connections
   - Deregister from Gordon
   - Clean up resources

2. DOCKER COMPOSE

   services:

       image: docker/gordon:latest
       ports: ["8000:8000"]

       image: dredge:latest
       ports: ["3001:3001"]
       environment:
