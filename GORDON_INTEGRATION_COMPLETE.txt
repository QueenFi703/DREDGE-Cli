🔧 HOW IT WORKS
=================

Request Flow:

  1. Client Request
     │
     ├─ GET /gordon/health
     │
  2. FastAPI Routes
     │
     ├─ Router matching
     ├─ Endpoint handler
     │
  3. Error Handling
     │
     ├─ Try/catch
     ├─ Exception handler
     │
  4. Response
     │
     ├─ 200 OK (success)
     ├─ 500 Error (with details)
     ├─ Graceful degradation
     │
  5. Logging
     │
     └─ Operation logged

Adapter Mounting:

  1. Core Gateway Startup
     │
  2. mount_adapters() called
     │
  3. Try to import Gordon adapter
     │
     ├─ Success → Mount router
     ├─ Failure → Log warning, continue
     │
  4. Try to import other adapters
     │
     ├─ Success → Mount each
     ├─ Failure → Log, register as disabled
     │
  5. Gateway Ready
     │
     └─ All available adapters mounted
