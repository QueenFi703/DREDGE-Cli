🎯 THE PATTERN
==============

What Vercel Sees:
  app = FastAPI()

What's Actually Running:
  FastAPI (ASGI) Core
    ├─ Native ASGI routes
    └─ Flask (WSGI) legacy adapters mounted via WSGIMiddleware

Result:
  ONE ASGI application that handles both FastAPI and Flask routes
  NO dual servers
  NO conditional logic
  Clean, professional architecture


═══════════════════════════════════════════════════════════════════════════════


📊 ARCHITECTURE
================

Layer 1: Vercel / ASGI Server
  └─ Sees: app = FastAPI()
     └─ Serves on: 1 port, 1 process

Layer 2: FastAPI Core (ASGI)
  ├─ Route: GET /                    (native FastAPI)
  ├─ Route: GET /health              (native FastAPI)
  ├─ Route: GET /status              (native FastAPI)
  ├─ Route: GET /adapters            (native FastAPI)
  └─ Mount: /legacy → WSGIMiddleware (Flask adapter)

Layer 3: Flask Legacy Adapter (WSGI)
  ├─ Route: GET /legacy/health       (Flask via WSGI)
  ├─ Route: GET /legacy/status       (Flask via WSGI)
  ├─ Route: GET /legacy/info         (Flask via WSGI)
  └─ Route: GET /legacy/hello        (Flask via WSGI)

How It Works:
  1. Request arrives at FastAPI (ASGI)
  2. FastAPI routes check:
     ├─ If /legacy/* → Pass to WSGIMiddleware
     │  └─ WSGIMiddleware converts ASGI → WSGI
     │     └─ Flask handles request
     │        └─ Response converted back to ASGI
     └─ Otherwise → Handle in FastAPI directly
  3. Response returns to client as ASGI

🚀 HOW TO USE
==============

1. Local Development:

   Starts on http://127.0.0.1:8000
   Both FastAPI and Flask routes accessible


2. Test FastAPI Routes (ASGI):

   curl http://127.0.0.1:8000/

   curl http://127.0.0.1:8000/legacy/health

   curl http://127.0.0.1:8000/legacy/hello


4. Interactive API Docs:

   (Shows FastAPI routes; Flask routes are mounted separately)

   (Vercel sees single ASGI FastAPI application)

🔧 ADDING MORE FLASK ADAPTERS
==============================

Step 1: Create Flask app in flask_legacy_adapters.py:

  def create_my_legacy_app() -> Flask:
      app = Flask(__name__)
      
      @app.route('/endpoint', methods=['GET'])
      def my_endpoint():
          return jsonify({"data": "value"})
      
      return app


Step 2: Mount in hybrid_gateway.py mount_adapters():

  my_app = create_my_legacy_app()
  app.mount("/legacy/myapp", WSGIMiddleware(my_app))
  logger.info("[Mount] My legacy app mounted at /legacy/myapp")


Step 3: Access:

  http://127.0.0.1:8000/legacy/myapp/endpoint


That's it! Your Flask app is now part of the ASGI gateway.
