PORT CONFIGURATION
============================================================================

Port 3002: MCP Server (Model Context Protocol)
  - Role: Provides tool definitions and capabilities
  - URL: http://127.0.0.1:3002
  - Access: All MCP tools and capabilities
  - Docs: http://127.0.0.1:3002/docs

Port 8001: DREDGE Server (Execution Layer)
  - Role: Plan execution and resource management
  - URL: http://127.0.0.1:8001
  - Features: Execute plans, manage resources, telemetry
  - Docs: http://127.0.0.1:8001/docs

Port 8080: Gateway (Fallback / Primary)
  - Role: API Gateway and frontend
  - URL: http://127.0.0.1:8080
  - MCP Endpoint: http://127.0.0.1:8080/mcp
  - Dashboard: http://127.0.0.1:8080/dashboard
  - API Docs: http://127.0.0.1:8080/swagger

============================================================================
HOW TO START ALL SERVERS
============================================================================

Option 1: Multi-Server Launcher (Recommended)
  python start_servers.py
  
  This starts all three servers in sequence:
    1. MCP Server (3002)
    2. DREDGE Server (8001)
    3. Gateway (8080)

Option 2: Individual Servers
  Terminal 1: python mcp_server.py
  Terminal 2: python dredge_server.py
  Terminal 3: python core_gateway.py

Option 3: Docker Deployment
  docker build -f Dockerfile.railway -t dredge:latest .
  
  Configure ports:
    - EXPOSE 3002 8001 8080
    - MCP_PORT=3002
    - DREDGE_PORT=8001
    - GATEWAY_PORT=8080

DEPLOYMENT CONFIGURATION
============================================================================

For Railway/Vercel Deployment:

Environment Variables:
  MCP_PORT=3002
  DREDGE_PORT=8001
  GATEWAY_PORT=8080
  MCP_URL=http://127.0.0.1:3002
  DREDGE_URL=http://127.0.0.1:8001
  GATEWAY_URL=http://127.0.0.1:8080

Dockerfile Configuration:
  EXPOSE 3002 8001 8080
  
  Start Command:
    CMD python start_servers.py

vercel.json Configuration:
  {
    "buildCommand": "pip install -r requirements.txt",
    "devCommand": "python start_servers.py",
    "functions": {
      "mcp_server.py": {"memory": 1024},
      "dredge_server.py": {"memory": 512},
      "core_gateway.py": {"memory": 512}
    }
  }

railway.toml Configuration:
  [build]
  builder = "dockerfile"
  dockerfile = "Dockerfile.railway"
  
  [deploy]
  startCommand = "python start_servers.py"
  
  [[services]]
  name = "mcp"
  port = 3002
  
  [[services]]
  name = "dredge"
  port = 8001
  
  [[services]]
  name = "gateway"
  port = 8080
