✅ VERCEL DEPLOYMENT
====================

Configuration (Option 1 - Direct):

pyproject.toml:
  [tool.vercel]
  entrypoint = "full_web_server:app"
  buildCommand = "pip install -r requirements.txt"

vercel.json:
  {
    "buildCommand": "pip install -r requirements.txt",
    "functions": {
      "full_web_server.py": {
        "memory": 512,
        "maxDuration": 60
      }
    }
  }


Configuration (Option 2 - Through Gateway):

pyproject.toml:
  [tool.vercel]
  entrypoint = "api.gateway:app"
  buildCommand = "pip install -r requirements.txt"

(api.gateway.py tries full_web_server first)


Deploy:
  vercel --prod

Result:
  https://your-project-name.vercel.app
  All endpoints live on HTTPS

📋 ROUTES CONVERSION
====================

Health Check:

Flask (Old):
  @app.route('/health')
  def health():
      return jsonify({"status": "healthy"})

FastAPI (New):
  @app.get("/health")
  async def health():
      return {"status": "healthy"}


Dashboard:

Flask (Old):
  @app.route('/dashboard')
  def dashboard():
      return send_file(..., mimetype='text/html')

FastAPI (New):
  @app.get("/dashboard")
  async def dashboard():
      return FileResponse(..., media_type='text/html')


Insight Lifting:

Flask (Old):
  @app.route('/api/dredge/lift', methods=['POST'])
  def lift_insight():
      data = request.get_json()
      if not data or 'insight' not in data:
          return jsonify({"error": "..."}), 400
      return jsonify({...})

FastAPI (New):
  class InsightRequest(BaseModel):
      insight: str
  
  @app.post("/api/dredge/lift")
  async def lift_insight(request: InsightRequest):
      # Validation automatic, type-safe
      return InsightResponse(...)
