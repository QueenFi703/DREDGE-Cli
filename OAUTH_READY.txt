🔧 SETUP WORKFLOW
=================

Total Time: 15 minutes

STEP 1: GitHub OAuth (2 minutes)
   - Go to: https://github.com/settings/developers
   - Create new OAuth App
   - Fill: Name=DREDGE Studio, Callback=http://localhost:3000/auth/github/callback
   - Copy: Client ID and Client Secret

STEP 2: Google OAuth (5 minutes)
   - Go to: https://console.developers.google.com/
   - Create new project: DREDGE Studio
   - Enable Google+ API
   - Create OAuth 2.0 Client ID (Web)
   - Add URIs for http://localhost:3000
   - Copy: Client ID and Client Secret

STEP 3: Update .env (2 minutes)
   - Edit: dredge-cli-repo/.env
   - Add GitHub credentials
   - Add Google credentials
   - Keep SECRET_KEY as-is

STEP 4: Restart Server (1 minute)
   - Stop: stop_background_job job_1781560856_3
   - Start: python -m dredge.server
   - Wait for startup message

STEP 5: Test Login (1 minute)
   - Open: http://localhost:3000/auth/login
   - Click GitHub or Google button
   - Complete OAuth flow
   - Login successful!

🔐 GETTING CREDENTIALS
======================

GitHub:
  1. Visit: https://github.com/settings/developers
  2. Click: "New OAuth App"
  3. Register app with callback: http://localhost:3000/auth/github/callback
  4. Copy: Client ID
  5. Click: "Generate a new client secret"
  6. Copy: Client Secret

Google:
  1. Visit: https://console.developers.google.com/
  2. Create project: DREDGE Studio
  3. Enable: Google+ API
  4. Create: OAuth 2.0 Client ID (Web Application)
  5. Add URIs: http://localhost:3000 and http://localhost:3000/auth/google/callback
  6. Copy: Client ID and Client Secret

🛑 IF SOMETHING GOES WRONG
===========================

Service Won't Start:
  - Check logs: view_background_job job_1781560856_3
  - Verify Python 3.10+ installed
  - Check port 3000 not in use
  - Restart: kill and start fresh

OAuth Not Working:
  - Check credentials in .env are correct
  - Verify no extra spaces in credentials
  - Check callback URLs match GitHub/Google settings
  - Restart server after .env changes
  - Clear browser cache and cookies
  - Try different browser or incognito mode

Login Page But No Buttons:
  - Check .env has both GitHub and Google credentials
  - Restart server
  - Check logs for OAuth registration messages
  - Verify credentials aren't empty
