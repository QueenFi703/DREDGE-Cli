📋 STEP-BY-STEP INSTRUCTIONS
=============================

STEP 1: CREATE GITHUB OAUTH APP
────────────────────────────────

1. Visit: https://github.com/settings/developers

2. Click: "New OAuth App"

3. Fill in Application Details:
   
   Application name:
      DREDGE Studio
   
   Homepage URL:
      http://localhost:3000
   
   Application description (optional):
      AI-powered security and development platform
   
   Authorization callback URL (IMPORTANT):
      http://localhost:3000/auth/github/callback

4. Click: "Register application"

5. You'll see two important values:
   - Client ID (visible immediately)
   - Client Secret (click "Generate a new client secret")

6. COPY BOTH VALUES - you'll need them in 5 minutes


STEP 2: CREATE GOOGLE OAUTH APP
─────────────────────────────────

1. Visit: https://console.developers.google.com/

2. Create New Project:
   - Click "Select a project" dropdown (top left)
   - Click "NEW PROJECT"
   - Name: DREDGE Studio
   - Click "Create"
   - Wait for project to be created

3. Enable Google+ API:
   - Go to "APIs & Services" → "Library"
   - Search: "Google+ API"
   - Click result
   - Click "Enable"

4. Create OAuth 2.0 Client:
   - Go to "APIs & Services" → "Credentials"
   - Click "Create Credentials" → "OAuth 2.0 Client ID"
   - Choose: "Web Application"
   - Name (optional): DREDGE Studio Web Client
   - Click "Create"

5. Configure Authorized URIs (VERY IMPORTANT):
   
   Authorized JavaScript origins:
      http://localhost:3000
   
   Authorized redirect URIs:
      http://localhost:3000/auth/google/callback

6. Click "Create"

7. Copy your credentials:
   - Client ID (looks like: 123456789.apps.googleusercontent.com)
   - Client Secret (long random string)

🚨 TROUBLESHOOTING
===================

Problem: "OAuth provider not configured"
────────────────────────────────────────

Cause:    .env credentials not set or server not restarted
Solution:
  1. Check .env file has credentials
  2. Verify no typos in variable names
  3. Restart server
  4. Check logs for OAuth messages


Problem: "Redirect URI mismatch" error
──────────────────────────────────────

Cause:    Callback URL doesn't match what you registered
Solution:
  1. In GitHub: Check "Authorization callback URL" = 
     http://localhost:3000/auth/github/callback
  2. In Google: Check "Authorized redirect URIs" includes
     http://localhost:3000/auth/google/callback
  3. Restart server


Problem: "Invalid Client ID" or "Invalid Secret"
─────────────────────────────────────────────────

Cause:    Credentials are wrong or have extra spaces
Solution:
  1. Copy credentials again carefully
  2. Remove any extra spaces
  3. Make sure you copied full strings
  4. Regenerate if unsure:
     - GitHub: Click "Regenerate client secret"
     - Google: Delete and recreate OAuth app


Problem: Login page doesn't show OAuth buttons
──────────────────────────────────────────────

Cause:    Server restarted before credentials set
Solution:
  1. Check .env has GITHUB_CLIENT_ID and GOOGLE_CLIENT_ID
  2. Verify they're not empty
  3. Stop server: stop_background_job job_1781560856_3
  4. Start server: python -m dredge.server
  5. Refresh browser


Problem: Can't access http://localhost:3000
───────────────────────────────────────────

Cause:    Server not running or port conflict
Solution:
  1. Check server is running: curl http://localhost:3000/health
  2. If not running, start it: python -m dredge.server
  3. If port conflict, use different port in .env
  4. Restart server
