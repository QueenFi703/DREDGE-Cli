🔑 REQUIRED CREDENTIALS
=======================

You need to create OAuth apps at:

GitHub:  https://github.com/settings/developers
Google:  https://console.developers.google.com/

Each will give you:
- Client ID
- Client Secret
- Callback/Redirect URLs

Store these in .env file (never in code)


🔒 ENVIRONMENT VARIABLES
========================

Required:
   SECRET_KEY               - Generated (run: python -c "import secrets; print(secrets.token_hex(32))")
   GITHUB_CLIENT_ID         - From GitHub OAuth App
   GITHUB_CLIENT_SECRET     - From GitHub OAuth App
   GOOGLE_CLIENT_ID         - From Google OAuth App
   GOOGLE_CLIENT_SECRET     - From Google OAuth App

Optional (local development):
   OAUTH_REDIRECT_BASE      - Default: http://localhost:3000
   FLASK_ENV                - Default: production
   FLASK_HOST               - Default: 0.0.0.0
   FLASK_PORT               - Default: 3000

🎯 STEP-BY-STEP QUICK GUIDE
===========================

1. Run setup wizard:
   python setup_oauth.py

2. Follow prompts to create GitHub OAuth App
   - Go to https://github.com/settings/developers
   - Click "New OAuth App"
   - Fill in details
   - Copy Client ID and Secret

3. Follow prompts to create Google OAuth App
   - Go to https://console.developers.google.com/
   - Create new project
   - Enable Google+ API
   - Create OAuth 2.0 Client ID
   - Copy Client ID and Secret

4. Wizard creates .env automatically

5. Start server:
   export $(cat .env | xargs)
   python -m dredge.server

6. Test login:
   http://localhost:3000/auth/login


🔍 TROUBLESHOOTING
==================

"OAuth provider not configured"
   → Environment variables not loaded
   → Run: export $(cat .env | xargs)
   → Check: echo $GITHUB_CLIENT_ID

"Redirect URI mismatch"
   → Callback URL doesn't match GitHub/Google settings
   → Check OAUTH_FIX_GUIDE.md Step 1.3 and 2.5

"Invalid Client ID"
   → Wrong credentials or typo
   → Double-check .env values (no extra spaces)
   → Regenerate credentials if needed

"Login buttons not working"
   → Check browser console (F12 → Console tab)
   → Verify server running: curl http://localhost:3000/health
   → Check firewall not blocking localhost:3000
