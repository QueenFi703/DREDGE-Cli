UNIFIED ROUTING ARCHITECTURE:
================================================================================

Client Request
      |
      v
Gordon Router (Auto-detect task type)
      |
      +---> [Simple Inference] ---> Orion /invoke (FAST)
      |
      +---> [Complex Pipeline] ---> DREDGE /pipeline (ADVANCED)
      |
      +---> [Hybrid] ---> Sequential (DREDGE + Orion)


AUTO-ROUTING LOGIC:
================================================================================

Route to ORION (Fast Inference):
  - Single operation needed
  - Quick response required
  - No chaining/sequencing
  - Example: "What is X?", "Summarize this"

Route to DREDGE (Pipeline):
  - Multiple sequential operations
  - Contains: pipeline, chain, dag, flow keywords
  - Needs caching or failover
  - Example: "Transform then translate then analyze"

Route to BOTH (Sequential):
  - Pipeline of inference steps
  - Complex reasoning needed
  - Example: "Analyze, then generate insights, then summarize"


EXAMPLE USAGE - PYTHON:
================================================================================

import httpx

# Example 1: Use Orion directly
async with httpx.AsyncClient() as client:
    resp = await client.post(
        "http://127.0.0.1:8080/invoke",
        json={
            "input": "What is machine learning?",
            "mode": "standard",
            "context": {"length": "short"}
        },
        headers={"x-api-key": "your-api-key"}
    )
    print(resp.json())

# Example 2: Use DREDGE directly
async with httpx.AsyncClient() as client:
    resp = await client.post(
        "http://127.0.0.1:3001/api/architecture/pipeline/execute",
        json={
            "input_data": {"text": "Your text"},
            "pipeline_type": "standard"
        }
    )
    print(resp.json())

# Example 3: Use Gordon routing (when bridge is running)
async with httpx.AsyncClient() as client:
    resp = await client.post(
        "http://127.0.0.1:9999/execute",
        json={
            "input": "Complex task needing multiple steps",
            "mode": "auto"
        }
    )
    print(resp.json())
