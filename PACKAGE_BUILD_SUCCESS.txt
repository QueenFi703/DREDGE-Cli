🚀 HOW TO UPLOAD TO PyPI
========================

STEP 1: Create PyPI Account
───────────────────────────
Go to: https://pypi.org/account/register/
Create your account


STEP 2: Generate API Token
──────────────────────────
Go to: https://pypi.org/manage/account/tokens/
Click "Create a new token"
Set scope to "Entire account"
Copy the token (save it securely!)


STEP 3: Install Twine (if not already installed)
─────────────────────────────────────────────────
cd dredge-cli-repo
python -m pip install twine


STEP 4: Upload to PyPI
──────────────────────
Option A - Interactive (Twine will ask for credentials):
  twine upload dist/*
  
  When prompted:
    Username: __token__
    Password: (paste your PyPI token)

Option B - With token in command:
  twine upload dist/* -u __token__ -p pypi-AgEIcHlwaS5vcmc...

Option C - Using environment variable:
  export TWINE_PASSWORD="pypi-AgEIcHlwaS5vcmc..."
  twine upload dist/*
