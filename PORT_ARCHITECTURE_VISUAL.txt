SECURITY LAYERS
================

Layer 1: Firewall
  Only port 9000 exposed to internet
  Internal services on 8000, 8001, 8080, 3001

Layer 2: HTTPS/TLS
  Encrypt data in transit
  Certificate validation

Layer 3: API Key Authentication
  x-api-key header required
  SHA-256 hashing with salt

Layer 4: Rate Limiting
  Max requests per month by tier
  Returns 429 if exceeded

Layer 5: Audit Logging
  Track all requests
  Admin access logged

TROUBLESHOOTING QUICK REFERENCE
================================

Port 9000 not responding?
  → Make sure unified_auth_gateway.py is running

Connection refused on 8080?
  → Orion not running on 8080

401 Unauthorized?
  → Missing x-api-key header
  → Invalid key format

429 Too Many Requests?
  → Rate limit exceeded
  → Check usage with GET /usage

502 Bad Gateway?
  → Backend service (8000, 8001, 8080, 3001) not responding
  → Check that service is running
