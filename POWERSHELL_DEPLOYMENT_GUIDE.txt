📁 ENTRY POINT: app.py
======================

What is app.py?
  - Main ASGI application entry point
  - Located in project root (./app.py)
  - Imports unified_auth_gateway as the FastAPI app
  - Vercel recognizes this filename automatically

Why app.py?
  Vercel looks for these filenames (in order):
    1. app.py          ← We created this! ✅
    2. index.py
    3. server.py
    4. main.py
    5. wsgi.py
    6. asgi.py


Contents of app.py:
```python
from unified_auth_gateway import app as gateway_app

# This is what Vercel deploys
app = gateway_app

# Health check endpoint
@app.get("/health")
async def root_health():
    return {"status": "healthy", ...}

# If running locally
if __name__ == "__main__":
    uvicorn.run("app:app", host="127.0.0.1", port=9000)
```

🎯 COMMON POWERSHELL ISSUES & FIXES
====================================

Issue: "PowerShell is disabled on this system"
Solution:
  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  Then try again: .\test-and-deploy.ps1


Issue: "python: The term 'python' is not recognized"
Solution:
  1. Add Python to PATH or
  2. Use: py --version (Windows alias)
  3. Or: python3 --version


Issue: "pip: command not found"
Solution:
  1. Ensure Python installed: python --version
  2. Try: python -m pip --version
  3. If not working, reinstall Python


Issue: "Cannot find module unified_auth_gateway"
Solution:
  Check file exists: Test-Path unified_auth_gateway.py
  Should show: True
  If False, you're in wrong directory


Issue: "Connection refused on port 9000"
Solution:
  Port 9000 might be in use:
  Get-NetTcpConnection -LocalPort 9000
  Kill process if needed:
  Stop-Process -Id <PID> -Force


Issue: "Vercel command not found"
Solution:
  1. Install: npm install -g vercel
  2. Verify: vercel --version
  3. Close and reopen PowerShell


Issue: "Error during deploy: No frameworks detected"
Solution:
  Vercel can't find app.py
  Check: Test-Path app.py
  If False, file is missing
  If True, restart PowerShell and try again

🔐 ENVIRONMENT SETUP (OPTIONAL)
================================

Create .env file for local testing:
──────────────────────────────────
# .env (local only, don't commit)
PYTHONUNBUFFERED=true
FLASK_ENV=development
LOG_LEVEL=INFO

Load environment in PowerShell:
  Get-Content .env | ForEach-Object {
    if ($_ -match '^\s*([^=]+)=(.*)$') {
      $name = $matches[1].Trim()
      $value = $matches[2].Trim()
      [Environment]::SetEnvironmentVariable($name, $value, "Process")
    }
  }

Verify environment:
  $env:PYTHONUNBUFFERED
