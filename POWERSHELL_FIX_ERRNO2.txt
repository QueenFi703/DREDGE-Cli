⚠️  ERRNO 2 ERROR
=================

Error Message:
  errno 2: No such file or directory

Cause:
  - Python can't find required files
  - Wrong working directory
  - Missing dependencies
  - Import path issues


🔧 FIX IN POWERSHELL (5 STEPS)
===============================

Step 1: Run Diagnostic Script
──────────────────────────────
Open PowerShell in DREDGE-Cli directory:

  cd DREDGE-Cli
  .\diagnose.ps1

This will check:
  ✅ Current directory
  ✅ app.py exists
  ✅ Python installed
  ✅ FastAPI installed
  ✅ Imports working
  ✅ App can start


Step 2: Install Dependencies
─────────────────────────────
If diagnostic shows missing packages:

  pip install -r requirements.txt

Or upgrade:

  pip install --upgrade -r requirements.txt


Step 3: Verify Python Path
──────────────────────────
Check Python can find modules:

  python -c "import sys; print('\n'.join(sys.path))"

Should include current directory (.)


Step 4: Test Individual Imports
────────────────────────────────
Test each import separately:

  python -c "import fastapi; print('FastAPI: OK')"
  python -c "import uvicorn; print('Uvicorn: OK')"
  python -c "from unified_auth_gateway import app; print('Gateway: OK')"
  python -c "from app import app; print('App.py: OK')"


Step 5: Start App with Verbose Output
──────────────────────────────────────
Start with detailed error messages:

  python -u app.py

The -u flag ensures unbuffered output so you see errors immediately.

Look for:
  ✅ "Successfully imported unified_auth_gateway"
  ✅ "Starting on http://127.0.0.1:9000"
  ❌ Any ImportError or traceback

📋 COMMON ERRNO 2 SOLUTIONS
============================

Issue 1: Wrong Working Directory
─────────────────────────────────
Solution:

  # Verify you're in the right directory
  Get-Location
  
  # Should show: .../DREDGE-Cli
  
  # If not, navigate there:
  cd C:\path\to\DREDGE-Cli  # Update path
  
  # Verify files exist:
  Test-Path app.py              # Should be True
  Test-Path unified_auth_gateway.py  # Should be True


Issue 2: Missing Dependencies
──────────────────────────────
Solution:

  # Install all dependencies
  pip install -r requirements.txt
  
  # Or manually install core packages:
  pip install fastapi uvicorn httpx python-dotenv pydantic


Issue 3: Python Path Issues
────────────────────────────
Solution:

  # Start Python and check path
  python
  
  # Inside Python:
  import sys
  print(sys.path)
  
  # Should include '.' (current directory)
  # Exit with: exit()


Issue 4: Module Import Errors
──────────────────────────────
Solution:

  # Test imports step by step:
  python -c "from unified_auth_gateway import app"
  
  # If this fails, check unified_auth_gateway.py syntax:
  python -m py_compile unified_auth_gateway.py


Issue 5: app.py Has Syntax Errors
──────────────────────────────────
Solution:

  # Check for syntax errors:
  python -m py_compile app.py
  
  # Should show: OK (no output = success)
  # If error shown, file has syntax issues

🔍 DETAILED DEBUGGING
====================

If still getting errno 2, check:

1. Current Directory:
   Get-Location
   # Shows: C:\...\DREDGE-Cli

2. List Files:
   Get-ChildItem app.py
   Get-ChildItem unified_auth_gateway.py

3. Python Executable:
   which python
   python -c "import sys; print(sys.executable)"

4. Python Version:
   python --version
   # Should be 3.10 or higher

5. Module Search Path:
   python -c "import sys; [print(p) for p in sys.path]"
   # Should include current directory

6. Check for hidden imports:
   python -c "from app import app; print(app)"

7. Run app with extra verbosity:
   python -u app.py 2>&1 | Tee-Object -FilePath app_log.txt

   # Then read the log:
   Get-Content app_log.txt
