AUTHENTICATION
==============

Header Format:
  x-api-key: orion_key_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Example Requests:

# No auth (public)
curl http://127.0.0.1:9000/health

# With auth (protected)
curl -H "x-api-key: orion_key_xxx" \
  http://127.0.0.1:9000/orion/invoke

# Response includes rate limit headers
# X-RateLimit-Limit: 10000
# X-RateLimit-Remaining: 9995
# X-RateLimit-Tier: pro

RESPONSE HEADERS
================

Rate Limiting Headers (Automatic):
  X-RateLimit-Limit       Total requests/month
  X-RateLimit-Remaining   Requests left this month
  X-RateLimit-Tier        Your subscription tier

Example:
  X-RateLimit-Limit: 10000
  X-RateLimit-Remaining: 9850
  X-RateLimit-Tier: pro

PYTHON INTEGRATION
==================

Using HTTPX:

import httpx

api_key = "orion_key_xxx"

async with httpx.AsyncClient() as client:
    # Call Orion through gateway
    resp = await client.post(
        "http://127.0.0.1:9000/orion/invoke",
        headers={"x-api-key": api_key},
        json={"input": "Hello", "mode": "standard"}
    )
    
    print(resp.json())
    print(f"Remaining: {resp.headers['X-RateLimit-Remaining']}")

TROUBLESHOOTING
===============

Gateway won't start on 9000:
  Solution: Check port is free: netstat -an | findstr 9000

Can't authenticate:
  Solution: Check x-api-key header format
  Format: x-api-key: orion_key_xxxxx

Rate limit hit:
  Solution: Check usage: GET /usage
  Solution: Upgrade tier or wait for reset

Backend service returns 502:
  Solution: Check backend is running
  Solution: Verify port number in PORT_CONFIG

"Key not found" on admin operations:
  Solution: Check you're using admin key with FULL_ACCESS mode
