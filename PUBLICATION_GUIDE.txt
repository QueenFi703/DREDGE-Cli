HOW TO PUBLISH TO PyPI
======================

Step 1: Create PyPI Account
  └─ Go to https://pypi.org/account/register/
  └─ Verify email
  └─ Enable two-factor authentication

Step 2: Generate API Token
  └─ Go to https://pypi.org/manage/account/tokens/
  └─ Create token with "Entire account" scope
  └─ Copy token (you won't see it again!)

Step 3: Create ~/.pypirc
  └─ Create file in home directory with credentials:

[testpypi]
repository = https://test.pypi.org/legacy/
username = __token__
password = pypi-AgEIcHlwaS5vcmc...

[pypi]
repository = https://upload.pypi.org/legacy/
username = __token__
password = pypi-AgEIcHlwaS5vcmc...

Step 4: Build Distribution
  cd dredge-cli-repo
  pip install build twine
  python -m build

Step 5: Test Upload (Recommended)
  twine upload --repository testpypi dist/*
  # Test at https://test.pypi.org/project/dredge-studio/

Step 6: Upload to Production PyPI
  twine upload dist/*

Step 7: Verify
  pip install dredge-studio
  dredge --version

ALTERNATIVE: Use Environment Variable
  export TWINE_PASSWORD="pypi-AgEIcHlwaS5vcmc..."
  twine upload dist/*

ALTERNATIVE: Use GitHub Actions
  1. Add PYPI_API_TOKEN to repository secrets
  2. Create git tag: git tag v2.0.0
  3. Push tag: git push origin v2.0.0
  4. CI/CD automatically publishes to PyPI

TROUBLESHOOTING
==============

Problem: "Twine not found"
Solution: pip install twine

Problem: "Authentication failed"
Solution: Check PyPI token, verify .pypirc format

Problem: "Distribution verification failed"
Solution: Run: twine check dist/*

Problem: "Version already exists"
Solution: Update version in setup.py and pyproject.toml

Problem: "Long description rendering error"
Solution: Ensure README.md is valid reStructuredText or Markdown
