                      PUBLIC API ENDPOINTS
════════════════════════════════════════════════════════════════════════════════

ALL ENDPOINTS NOW ACCESSIBLE VIA:
https://api.dredge.ai/

Authentication:
  GET  /auth/login              → Redirect to GitHub OAuth
  GET  /auth/github/callback    ← GitHub OAuth redirect
  GET  /auth/logout             → Logout
  GET  /auth/me                 → Current user profile (authenticated)
  GET  /auth/status             → Auth status

Health & Status:
  GET  /health                           → System health (PUBLIC)
  GET  /api/gordon/health                → Gordon bridge health (PUBLIC)
  GET  /api/architecture/health          → Architecture health (PUBLIC)

Gordon Integration:
  POST /api/gordon/start                 → Start bridge (authenticated)
  POST /api/gordon/stop                  → Stop bridge (authenticated)
  GET  /api/gordon/capabilities          → Advertise capabilities (PUBLIC)
  GET  /api/gordon/status                → Bridge status (authenticated)
  POST /api/gordon/task/execute          → Execute task (authenticated)

Architecture:
  POST /api/architecture/pipeline/execute → Execute DAG (authenticated)
  POST /api/architecture/translate        → Translation (authenticated)
  POST /api/architecture/analyze          → Analysis (authenticated)
  GET  /api/architecture/providers/status → Provider health (authenticated)

Dashboard:
  GET  /                    → API info (authenticated)
  GET  /advanced            → Dashboard (authenticated)
  GET  /quasimoto-gpu       → Visualization (authenticated)

                      DOMAIN SETUP (Optional)
════════════════════════════════════════════════════════════════════════════════

Current URL: https://api.dredge.ai (via Vercel)

To add custom domain:

1. PURCHASE DOMAIN
   Registrar: Namecheap, GoDaddy, Google Domains, etc.
   Domain: api.dredge.ai (or similar)

2. CONFIGURE DNS
   
   Add CNAME record:
   Name: api
   Value: cname.vercel.com.
   TTL: 3600

3. VERCEL SETUP
   
   Dashboard → Settings → Domains
   Add: api.dredge.ai
   
   Vercel provides SSL automatically

4. VERIFY
   
   dig api.dredge.ai
   
   Should resolve to Vercel IP
