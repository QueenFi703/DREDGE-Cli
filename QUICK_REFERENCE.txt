CURL EXAMPLES
=============

Health Check:
  curl http://127.0.0.1:8000/health

List Models:
  curl http://127.0.0.1:8000/api/advanced/models/list

Load Model:
  curl -X POST http://127.0.0.1:8000/api/advanced/models/load \
    -H "Content-Type: application/json" \
    -d '{"model_id":"quasimoto_4d"}'

Get Alerts:
  curl http://127.0.0.1:8000/api/advanced/dependabot/alerts

Lift Insight:
  curl -X POST http://127.0.0.1:8000/api/advanced/insights/lift \
    -H "Content-Type: application/json" \
    -d '{"insight_text":"Your text"}'

Build Swift:
  curl -X POST http://127.0.0.1:8000/api/advanced/swift/build \
    -H "Content-Type: application/json" \
    -d '{"optimization":"-O"}'

import requests

JAVASCRIPT EXAMPLES
===================

// Health check
fetch('http://127.0.0.1:8000/health')
  .then(r => r.json())

// List models
fetch('http://127.0.0.1:8000/api/advanced/models/list')
  .then(r => r.json())
  .then(d => console.log(d.quasimoto))

// Lift insight
fetch('http://127.0.0.1:8000/api/advanced/insights/lift', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({insight_text: 'Your insight'})
})
  .then(r => r.json())
  .then(d => console.log(d))

TROUBLESHOOTING
===============

Cannot connect:
  Check if server is running: python run_advanced_server.py
  Verify port 8000 is open

Endpoint 404:
  Check endpoint path spelling
  API base is: /api/advanced/

Dashboard not loading:
  Clear browser cache
  Try incognito window
  Check console for errors

API errors:
  Verify JSON format
  Check Content-Type header
  Review request body
