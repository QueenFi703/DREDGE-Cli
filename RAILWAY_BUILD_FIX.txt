4. SET ENVIRONMENT VARIABLES

                    RAILWAY TROUBLESHOOTING GUIDE
════════════════════════════════════════════════════════════════════════════════

BUILD FAILING?

1. CHECK BUILD LOGS
   railway logs -f --build
   
   Common issues:
   - Missing dependencies (add to requirements.txt)
   - Python version mismatch (use 3.10)
   - Module not found (check wsgi.py)

2. VERIFY FILES
   
   Required files:
   ✓ wsgi.py (WSGI entry point)
   ✓ Dockerfile.railway (multi-stage build)
   ✓ railway.toml (configuration)
   ✓ requirements.txt or requirements-railway.txt
   
   Check presence:
   git ls-files | grep -E "wsgi.py|Dockerfile.railway|railway.toml"

3. TEST LOCALLY
   
   Build locally:
   docker build -f Dockerfile.railway -t dredge-railway .
   
   Run locally:
   docker run -e PORT=3001 -p 3001:3001 dredge-railway
   
   Test:
   curl http://localhost:3001/health

4. CHECK ENVIRONMENT VARIABLES
   
   railway variables
   
   Should show:
   GITHUB_CLIENT_ID=...
   GITHUB_CLIENT_SECRET=...
   OAUTH_REDIRECT_BASE=...
   FLASK_ENV=production
   PYTHONUNBUFFERED=1

5. VERIFY DOCKERFILE
   
   Check:
   ✓ FROM python:3.10-slim (correct base)
   ✓ WORKDIR /app (correct path)
   ✓ COPY wsgi.py (entry point included)
   ✓ CMD ["gunicorn", "wsgi:app"] (correct command)
   ✓ HEALTHCHECK (health endpoint)


DEPLOYMENT STUCK?

1. CHECK HEALTH STATUS
   railway status
   
2. VIEW DETAILED LOGS
   railway logs -f
   
3. RESTART SERVICE
   railway restart
   
4. FORCE REBUILD
   railway up --build
   
5. CHECK RESOURCES
   railway status --verbose
   
   Verify:
   - CPU usage < 100%
   - Memory usage < 512MB
   - Disk space available


CONTAINER CRASHES?

1. CHECK STARTUP LOGS
   railway logs | tail -100
   
   Look for:
   - ImportError (missing module)
   - ModuleNotFoundError (Python path issue)
   - BindError (port already in use)
   - TimeoutError (service too slow to start)

2. VERIFY WSGI ENTRY POINT
   
   Test import:
   python -c "from wsgi import app; print(app)"
   
   Should output:
   <Flask 'wsgi'>

3. CHECK ENTRYPOINT SCRIPT
   
   Permissions:
   chmod +x entrypoint.sh
   
   Syntax:
   bash -n entrypoint.sh

4. INCREASE STARTUP TIME
   
   In railway.toml:
   [healthCheck]
   startPeriod = 60  # Increase from 20
