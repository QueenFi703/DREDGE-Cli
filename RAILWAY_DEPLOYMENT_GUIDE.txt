📋 DEPLOYMENT METHODS
======================

METHOD 1: Railway CLI (Recommended - Fastest)
─────────────────────────────────────────────

1. Install Railway CLI:
   npm install -g @railway/cli
   
   OR using pip:
   pip install railway

2. Login to Railway:
   railway login
   # Opens browser, authenticate with GitHub

3. Create Railway project:
   railway init
   # Choose project name: DREDGE-Integrated-Gateway
   # Choose environment: production

4. Link GitHub repository:
   railway link
   # Select: QueenFi703/DREDGE-Cli

5. Deploy:
   railway up
   # Deploys from current directory
   # Uses Dockerfile.railway
   # Watches logs in real-time

6. Get deployment URL:
   railway domain
   # Shows: https://dredge-integrated-gateway.railway.app


METHOD 2: Railway Dashboard (Web UI)
─────────────────────────────────────

1. Go to https://railway.app

2. Sign in with GitHub

3. Click "New Project"

4. Select "Deploy from GitHub repo"

5. Search: QueenFi703/DREDGE-Cli

6. Select repository

7. Configure:
   - Branch: master
   - Root: ./ (or leave default)
   - Dockerfile: Dockerfile.railway (auto-detected)

8. Click "Deploy"

9. View deployment:
   - Real-time logs
   - Status
   - Domain URL
   - Environment variables


METHOD 3: GitHub Integration (Auto-Deploy)
────────────────────────────────────────────

1. Connect GitHub to Railway account:
   - Go to Railway Dashboard
   - Settings → GitHub Integration
   - Authorize railway.app

2. Create new project from GitHub:
   - Railway Dashboard → New Project
   - Select "Deploy from GitHub repo"
   - QueenFi703/DREDGE-Cli

3. Auto-deploy on push:
   - Every git push to master automatically deploys
   - No manual commands needed
   - Logs visible in Railway Dashboard

✅ WHAT DEPLOYS
=================

Docker Build Process:

1. Reads Dockerfile.railway
2. Installs Python 3.10-slim
3. Copies requirements.txt
4. pip install -r requirements.txt
   - fastapi, uvicorn, httpx, pydantic
   - All cognitive modules
   - Security hardening

5. Copies entire project:
   ✅ core_gateway_integrated.py
   ✅ gpt_sol_reasoning_engine.py
   ✅ tresh_decision_layer.py
   ✅ cognitive_nervous_system.py
   ✅ security_hardening.py
   ✅ api/deployment.py (entry point)
   ✅ All supporting files

6. Sets environment:
   PYTHONUNBUFFERABLE=true
   PYTHONDONTWRITEBYTECODE=true

7. Starts application:
   python -m uvicorn api.deployment:app --host 0.0.0.0 --port $PORT

Result:
  Docker Image: ~500MB
  Container: Running with all three cognitive layers + security
  Endpoint: https://your-project.railway.app
