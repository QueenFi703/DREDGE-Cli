APPLICATIONS OPEN STATUS
============================================================================

Current Application State:

The applications_open endpoint reports whether Speedrun Alpha is accepting
new applications. Response includes:

  • status: OPEN / CLOSED / LIMITED / WAITLIST
  • applications_accepting: boolean
  • spots_available: integer (if limited)
  • deadline: ISO timestamp
  • application_window: Date range for acceptance

Example Status Response:
  {
    "status": "OPEN",
    "applications_accepting": true,
    "spots_available": 15,
    "deadline": "2026-02-28T23:59:59Z",
    "application_window": "2026-01-15 - 2026-02-28"
  }

ORDERED APPLICATION STEPS (5-STEP PROCESS)
============================================================================

Step 1: REGISTER
  Purpose: Initial project and founder registration
  Duration: 5-10 minutes
  Required Fields:
    - project_name
    - description
    - founder_name
    - founder_email
  Outcome: Project registered in system

Step 2: SCHEMA REGISTRATION
  Purpose: Register Alpha intake as project MCP
  Duration: 5 minutes
  Required Fields:
    - schema (application schema)
    - mcp_endpoint (project endpoint)
  Outcome: MCP endpoint activated for programmatic access

Step 3: INTAKE CONFIGURATION
  Purpose: Configure company and market details
  Duration: 10-15 minutes
  Required Fields:
    - company_stage
    - industry_category
    - funding_stage
    - market_size
  Outcome: Company profile created in Speedrun system

Step 4: VALIDATION
  Purpose: Verify all required fields are complete
  Duration: Automatic (seconds)
  Required Fields:
    - All previous steps verified
  Outcome: Application validated and ready for submission

Step 5: SUBMIT
  Purpose: Final submission for Speedrun review
  Duration: 1 minute
  Required Fields:
    - None (all previous steps completed)
  Outcome: Application submitted to a16z review team
