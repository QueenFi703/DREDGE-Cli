📡 GORDON API ENDPOINTS
════════════════════════════════════════════════════════════════════════════════

All endpoints at: http://localhost:3001/api/gordon/

┌─ Bridge Management ─────────────────────────────────────────────────────┐
│                                                                          │
│ GET /api/gordon/health                                                  │
│   → Quick health check                                                   │
│   → Returns: Gordon status, DREDGE status, bridge running               │
│                                                                          │
│ POST /api/gordon/start                                                   │
│   → Start Gordon bridge                                                  │
│   → Registers with Gordon, begins listening for tasks                   │
│                                                                          │
│ POST /api/gordon/stop                                                    │
│   → Stop Gordon bridge                                                   │
│   → Graceful shutdown, cleanup resources                                │
│                                                                          │
│ GET /api/gordon/status                                                   │
│   → Detailed status report                                               │
│   → Includes connection status, metrics, timestamps                     │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘

┌─ Task Execution ────────────────────────────────────────────────────────┐
│                                                                          │
│ POST /api/gordon/task/execute                                            │
│   → Execute task from Gordon                                             │
│   → Supports: pipeline, translate, analyze                               │
│   → Returns: Status, result, duration, error (if any)                   │
│                                                                          │
│ Request:                                                                 │
│   {                                                                      │
│     "task_id": "task_123",                                               │
│     "type": "translate",                                                 │
│     "input_data": {"text": "Hello", "target_language": "es"}            │
│   }                                                                      │
│                                                                          │
│ Response:                                                                │
│   {                                                                      │
│     "status": "success",                                                 │
│     "result": {"translated": "Hola"},                                    │
│     "duration": 0.245                                                    │
│   }                                                                      │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘

┌─ Capability Management ─────────────────────────────────────────────────┐
│                                                                          │
│ GET /api/gordon/capabilities                                             │
│   → Advertise DREDGE capabilities to Gordon                              │
│   → Returns: Supported task types, endpoints, version                   │
│   → Gordon uses this for task routing decisions                         │
│                                                                          │
│ Capabilities:                                                            │
│   1. pipeline_execution → /api/architecture/pipeline/execute             │
│   2. text_translation → /api/architecture/translate                      │
│   3. semantic_analysis → /api/architecture/analyze                       │
│   4. provider_management → /api/architecture/providers/status            │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
