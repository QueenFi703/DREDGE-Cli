DEPLOYMENT OPTIONS ON VERCEL
=============================

Option 1: Unified Auth Gateway (Recommended)
─────────────────────────────────────────────
Entry Point: unified_auth_gateway:app
URL: https://dredge-auth-gateway.vercel.app
Purpose: Central proxy routing to all backend services (8000, 8001, 8080, 3001)
Scaling: Automatic serverless scaling
Best For: Production gateway with multi-service routing

Option 2: Standalone Orion with Middleware
───────────────────────────────────────────
Entry Point: orion_gateway_authenticated:app
URL: https://orion-gateway.vercel.app
Purpose: Standalone Orion inference endpoint with authentication
Scaling: Automatic serverless scaling
Best For: Individual service deployment


🚀 QUICK START: DEPLOY TO VERCEL (5 MINUTES)
==============================================

Step 1: Install Vercel CLI (2 minutes)
───────────────────────────────────────
npm install -g vercel


Step 2: Deploy (2 minutes)
──────────────────────────
cd DREDGE-Cli

Follow prompts:

  ? Link to existing project? → N (first time) or Y (existing)
  ? What's your project's name? → dredge-auth-gateway
  ? In which directory is your code located? → .
  ? Want to modify these settings? → N

Wait for deployment...


Step 3: Verify Deployment (1 minute)
────────────────────────────────────
Your URL will be displayed:
  https://dredge-auth-gateway.vercel.app

Test:
  curl https://dredge-auth-gateway.vercel.app/health


CONFIGURATION: pyproject.toml
==============================

The pyproject.toml file includes Vercel configuration:

```toml
[tool.vercel]
# Primary deployment
[[tool.vercel.functions]]
entrypoint = "unified_auth_gateway:app"
memory = 512
maxDuration = 60
runtime = "python3.11"

# Alternative deployment
[[tool.vercel.functions]]
entrypoint = "orion_gateway_authenticated:app"
memory = 512
maxDuration = 60
runtime = "python3.11"

[tool.vercel.env]
PYTHONUNBUFFERED = "true"
FLASK_ENV = "production"
AUTH_STORAGE_PATH = "/tmp/api_keys.json"
```

This configuration:
  ✅ Specifies Python 3.11 runtime
  ✅ Sets 512MB memory per function
  ✅ 60-second timeout
  ✅ Environment variables configured
  ✅ Two entry points for flexibility


ENVIRONMENT VARIABLES ON VERCEL
================================

Set in Vercel Dashboard:

1. Go to: https://vercel.com/dashboard
2. Select: Your Project → Settings → Environment Variables
3. Add:

  PYTHONUNBUFFERED = true
  PYTHONDONTWRITEBYTECODE = true
  FLASK_ENV = production
  AUTH_STORAGE_PATH = /tmp/api_keys.json
  LOG_LEVEL = INFO
  ENABLE_RATE_LIMITING = true

Production Environment:
  ENVIRONMENT = production
  DEBUG = false
  SECRET_KEY = your-secure-random-key


DEPLOYING UNIFIED AUTH GATEWAY
===============================

Command:
  vercel --prod

This deploys: unified_auth_gateway:app

What it does:
  ✅ Central authentication proxy on single endpoint
  ✅ Routes to backend services (Orion, DREDGE, etc.)
  ✅ Automatic API key validation
  ✅ Rate limiting enforcement
  ✅ Usage tracking

Routing (through unified gateway):
  GET  https://your-url/health                    → Public health
  POST https://your-url/orion/invoke              → Routes to Orion (8080)
  GET  https://your-url/dredge/api/arch/health   → Routes to DREDGE (3001)
  POST https://your-url/admin/keys/create         → Create API key


DEPLOYING STANDALONE ORION
===========================

To deploy just Orion with middleware (not the gateway):

1. Edit vercel.json to set primary entrypoint:
   ```json
   {
     "buildCommand": "pip install -r requirements.txt",
     "functions": {
       "orion_gateway_authenticated.py": {
         "runtime": "python3.11"
       }
     }
   }
   ```

2. Deploy:
   vercel --prod

This deploys: orion_gateway_authenticated:app

What it does:
  ✅ Standalone Orion with unified middleware
  ✅ No gateway routing
  ✅ Authentication on /invoke, /health, etc.
  ✅ Admin panel for key management

CUSTOM DOMAIN ON VERCEL
=======================

Add your own domain (e.g., api.dredge.ai):

1. In Vercel Dashboard:
   Settings → Domains → Add Domain

2. Enter domain: api.dredge.ai

3. Vercel shows CNAME record to add:
   CNAME: cname.vercel.com

4. In your registrar (GoDaddy, Namecheap, etc.):
   Add CNAME record:
   Name: api
   Value: cname.vercel.com
   TTL: 3600

5. Wait for DNS propagation (5-24 hours)

6. Test:
   curl https://api.dredge.ai/health


API KEY STORAGE ON VERCEL
=========================

Important: Vercel uses ephemeral filesystem

On first deploy:
  ✅ API keys stored in /tmp/api_keys.json
  ✅ Works fine for initial setup

Issue: /tmp cleared on restart

Solutions:

Option 1: Use Environment Variables
────────────────────────────────────
Store API key hashes in environment:
  Add secrets to Vercel dashboard
  Load from environment in code

Option 2: Use External Database
────────────────────────────────
Connect to PostgreSQL/MongoDB:
  - Vercel PostgreSQL add-on
  - AWS RDS
  - MongoDB Atlas

Option 3: Use Vercel KV (Redis)
───────────────────────────────
Vercel KV for persistent storage:
  Dashboard → Storage → KV
  Fast key-value store

Recommended: Use Vercel KV or Database for production

ERROR TROUBLESHOOTING
====================

Build Error: Module not found
  Solution: Check requirements.txt has all imports
  Fix: pip freeze > requirements.txt

Runtime Error: ModuleNotFoundError
  Solution: Ensure module is imported correctly
  Fix: Check import statements and paths

Timeout Error: Function timed out
  Solution: Increase maxDuration in config
  Fix: Set maxDuration to 60 (max for Vercel)

Import Error: Cannot import FastAPI
  Solution: Install dependencies
  Fix: requirements.txt must include fastapi

API Key Storage Missing
  Solution: Use external database/KV store
  Fix: Add database connection to code
