THE PROBLEM
===========

Error Message:
  "No Flask entrypoint found in default location, but found potential 
   entrypoints: orion_gateway_authenticated.py (variable: app) and 
   unified_auth_gateway.py (variable: app)"

Root Cause:
  - Vercel auto-detected Flask but we're using FastAPI
  - Vercel couldn't find the default Flask app.py
  - Found our FastAPI apps but didn't know how to handle them


THE SOLUTION
============

Files Created:
  ✅ vercel.json         - Explicit Vercel configuration (UPDATED)
  ✅ api/gateway.py      - Gateway API route entry point
  ✅ api/orion.py        - Standalone Orion API route entry point
  ✅ vercel_app.py       - Main ASGI app (for reference)

These files tell Vercel:
  1. Use Python 3.11 runtime (not Flask detection)
  2. Use api/gateway.py as primary entry point
  3. Use api/orion.py as alternative entry point
  4. Handle FastAPI/ASGI applications correctly


📝 DEPLOYMENT CONFIGURATION
============================

vercel.json Structure:
```json
{
  "framework": null,                    // ← Don't auto-detect
  "python": {"version": "3.11"},        // ← Use Python 3.11
  "functions": {
    "api/gateway.py": {                 // ← Primary entry point
      "runtime": "python3.11"
    },
    "api/orion.py": {                   // ← Alternative entry point
      "runtime": "python3.11"
    }
  }
}
```

This configuration:
  ✅ Disables auto-detection (framework: null)
  ✅ Explicitly defines Python 3.11
  ✅ Sets up two API routes
  ✅ Both resolve to FastAPI apps

❌ COMMON ISSUES & FIXES
========================

Issue: Build fails with "ModuleNotFoundError"
  Cause: Missing dependency
  Fix: Add to requirements.txt
  Command: pip freeze > requirements.txt

Issue: "No module named 'unified_auth_gateway'"
  Cause: Import path wrong in api/gateway.py
  Fix: Check sys.path.insert line
  Verify: api/gateway.py imports correctly locally

Issue: "404 Not Found" on /api/gateway/health
  Cause: Endpoint not deployed
  Fix: Check vercel logs
  Command: vercel logs --follow

Issue: "Port already in use" locally
  Cause: Testing conflict
  Fix: Use different ports or kill process
  Command: lsof -i :9000 (macOS/Linux)

Issue: Health check times out
  Cause: Backend services not accessible
  Fix: Ensure backend services running
  Check: Are Orion (8080), DREDGE (3001) running?

Issue: API key authentication fails
  Cause: Key not in storage
  Fix: Create new test key first
  Command: curl -X POST /admin/keys/create
