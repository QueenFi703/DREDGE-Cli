❌ WHAT NOT TO USE IN VERCEL.JSON
==================================

INVALID Properties (will cause errors):

❌ "python": {...}           ← Use runtime in functions instead
❌ "version": "3.11"         ← Use runtime in functions instead
❌ "engines": {...}          ← Not for Vercel
❌ "scripts": {...}          ← Not Vercel syntax
❌ "node_version": "..."     ← Use runtime in functions
❌ "buildDir": "..."         ← Use outputDirectory instead


CORRECT Properties:

✅ "runtime": "python3.11"   ← In functions block
✅ "memory": 512              ← In functions block
✅ "maxDuration": 60          ← In functions block
✅ "buildCommand": "..."      ← Root level
✅ "installCommand": "..."    ← Root level
✅ "outputDirectory": "."     ← Root level
