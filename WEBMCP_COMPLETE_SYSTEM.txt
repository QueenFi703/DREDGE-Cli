============================================================================
WHAT IS WEBMCP?
============================================================================

webMCP is a complete web-based agentic system that combines:

1. DREDGE Orchestration Architecture
   - Event-based state management
   - Multi-agent coordination
   - Task routing and sequencing
   - State transitions and workflows

2. Model Context Protocol (MCP)
   - Standard tool definitions
   - Resource management
   - Capability negotiation
   - Extensibility framework

3. Web-based Interface
   - Polished gradient UI
   - Real-time event streaming
   - Agent management dashboard
   - Task orchestration controls

4. Production-Ready Foundation
   - FastAPI backend
   - WebSocket streaming
   - RESTful API
   - Performance optimized

============================================================================
AGENT ORCHESTRATION PATTERNS
============================================================================

Pattern 1: Sequential Pipeline
  Input → analysis-agent → planning-agent → execution-agent → Output
  Use when: Need ordered processing

Pattern 2: Parallel Processing
  Input → [research-agent, analysis-agent] (parallel) → planning-agent → Output
  Use when: Multiple independent analyses needed

Pattern 3: Feedback Loop (Iterative)
  Input → analysis-agent → [feedback] → planning-agent → execution-agent
  → [evaluate] → [loop back if needed]
  Use when: Refinement and optimization needed

Pattern 4: Hierarchical Delegation
  Planning Agent receives goal
    ├─ Delegates to analysis-agent (subtask 1)
    ├─ Delegates to research-agent (subtask 2)
    ├─ Coordinates results
    └─ Returns to execution-agent
  Use when: Complex hierarchical tasks

WEBSOCKET EVENT STREAM
============================================================================

JavaScript Client Example:

```javascript
// Connect to event stream
const ws = new WebSocket('ws://127.0.0.1:3000/ws/events');

// Handle new events
ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('Event:', data.type);
  console.log('Timestamp:', data.timestamp);
  console.log('Data:', data.data);
  
  // Update UI based on event type
  if (data.type === 'task_emitted') {
    updateTaskCounter();
  } else if (data.type === 'task_completed') {
    updateCompletedCounter();
  }
};

ws.onerror = (error) => {
  console.error('WebSocket error:', error);
};

ws.onclose = () => {
  console.log('Connection closed');
};
```

Event Types:
  • agent_registered: New agent registered
  • task_emitted: Task sent to agent
  • task_completed: Task finished
  • state_updated: System state changed

EXTENDING WEBMCP
============================================================================

Add Custom Agent:

```python
from webmcp import orchestrator

# Register new agent
orchestrator.register_agent(
    "custom-agent",
    "custom_type",
    {"timeout": 60, "config_key": "value"}
)
```

Create Agent Behavior:

```python
import asyncio
from webmcp import orchestrator

async def custom_agent_handler(task_id, task_type, payload):
    """Custom agent implementation"""
    try:
        # Process task
        result = await process_task(payload)
        
        # Mark complete
        orchestrator.complete_task("custom-agent", task_id, result)
    except Exception as e:
        orchestrator.complete_task("custom-agent", task_id, {"error": str(e)})

# Register handler
asyncio.create_task(custom_agent_handler(task_id, task_type, payload))
```

Implement MCP Tool:

```python
from mcp_server import mcp_app

@mcp_app.post("/tools/custom-tool")
async def custom_tool(request):
    body = await request.json()
    # Implementation
    return {"result": "..."}
```

============================================================================
TROUBLESHOOTING
============================================================================

Issue: WebSocket connection fails in browser
  Fix: Check firewall, ensure port 3000 is open
  
Issue: Agents show "offline"
  Fix: Verify orchestrator running, check agent registration
  
Issue: Events not updating in real-time
  Fix: Check browser console for WebSocket errors
  
Issue: High memory usage
  Fix: Reduce event log size, clear old events periodically
  
Issue: Slow performance
  Fix: Check system resources, profile agent tasks
  
Issue: CORS errors in browser
  Fix: CORS is enabled by default, check firewall
