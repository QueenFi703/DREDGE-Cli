🎤 HOW TO USE WHISPER TINY
==========================

Method 1: Command Line (Simplest)
─────────────────────────────────

Transcribe an audio file:
  whisper audio.mp3

With options:
  whisper audio.mp3 --model tiny --language en

Output formats:
  whisper audio.mp3 --output_format txt
  whisper audio.mp3 --output_format srt
  whisper audio.mp3 --output_format json
  whisper audio.mp3 --output_format vtt

Full options:
  whisper audio.mp3 --help


Method 2: Python API
────────────────────

Basic usage:
  import whisper
  
  model = whisper.load_model("tiny")
  result = model.transcribe("audio.mp3")
  print(result["text"])

With options:
  result = model.transcribe(
      "audio.mp3",
      language="en",
      verbose=True,
      temperature=0.0
  )

Processing multiple files:
  import whisper
  model = whisper.load_model("tiny")
  
  files = ["audio1.mp3", "audio2.mp3", "audio3.mp3"]
  for file in files:
      result = model.transcribe(file)
      print(f"{file}: {result['text']}")


Method 3: Get More Detail
──────────────────────────

Include timestamps:
  import whisper
  
  model = whisper.load_model("tiny")
  result = model.transcribe("audio.mp3", verbose=True)
  
  # Print with timestamps
  for segment in result["segments"]:
      print(f"[{segment['start']:.2f}s - {segment['end']:.2f}s] {segment['text']}")

Get detected language:
  result = model.transcribe("audio.mp3")
  print(f"Detected language: {result['language']}")

🔊 EXAMPLE: TRANSCRIBE A FILE
=============================

Save as: transcribe.py

```python
import whisper

# Load model
model = whisper.load_model("tiny")

# Transcribe audio
result = model.transcribe("audio.mp3")

# Save transcript

    f.write(result["text"])

print(f"Detected language: {result['language']}")

```

Run:

🚀 INTEGRATION EXAMPLES
======================

1. Transcribe YouTube audio:
   
   # Download audio from YouTube
   youtube-dl -x --audio-format mp3 https://youtube.com/watch?v=...
   
   # Transcribe it
   whisper downloaded_audio.mp3

2. Real-time transcription (from microphone):
   
   import whisper
   import sounddevice as sd
   import soundfile as sf
   
   model = whisper.load_model("tiny")
   
   # Record audio
   print("Recording... speak now")
   audio = sd.rec(int(10 * 16000), samplerate=16000, channels=1)
   sd.wait()
   
   # Save and transcribe
   sf.write("temp.wav", audio, 16000)
   result = model.transcribe("temp.wav")
   print(result["text"])

3. Batch processing:
   
   import whisper
   from pathlib import Path
   
   model = whisper.load_model("tiny")
   audio_files = Path(".").glob("*.mp3")
   
   for audio_file in audio_files:
       result = model.transcribe(str(audio_file))
       output_file = audio_file.with_suffix(".txt")
       output_file.write_text(result["text"])
       print(f"Processed: {audio_file}")
