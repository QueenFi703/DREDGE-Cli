Overview

DREDGE Studio Advanced provides 26 REST API endpoints for AI/ML model management, Swift development, security alerts, and visualization.

Features

  • Model Management (Quasimoto, String Theory)
  • MCP Operations (Model Context Protocol)
  • Insight Lifting (DREDGE Pipeline)
  • Swift Toolchain (Build, Test, Deploy)
  • Dependabot Alerts (Security Management)
  • API Endpoint Tester
  • Container Status Monitor
  • String Theory Visualization
  • Quasimoto Wave Function Plotter
  • Code Generation Templates

Base URL

http://127.0.0.1:8000/api/advanced

Response Format

All responses are JSON with consistent structure:

{
  "status": "success|error",
  "data": { ... },
  "timestamp": "ISO-8601",
  "execution_time_ms": 123.45
}

1. Model Management NEW

GET/models/list
List all available Quasimoto and String Theory models
Response: 
{
  "quasimoto": [
    {
      "id": "quasimoto_1d",
      "name": "1D Wave Function",
      "parameters": 8
    },
    ...
  ],
  "string_theory": [...]
}
POST/models/load
Load a model by ID with optional configuration
Request Body: 
{
  "model_id": "quasimoto_4d",
  "config": { }
}
POST/models/{id}/inference
Run inference on loaded model
Request Body: 
{
  "parameters": { }
}
POST/models/{id}/benchmark
Benchmark model performance
Request Body: 
{
  "iterations": 100
}

2. MCP Operations NEW

GET/mcp/operations
List available MCP operations
POST/mcp/execute
Execute MCP operation
Request Body: 
{
  "operation": "unified_inference",
  "params": {
    "dredge_insight": "...",
    "quasimoto_coords": [0.5, 0.5, 0.5],
    "string_modes": [1, 2, 3]
  }
}

3. Insight Lifting NEW

POST/insights/lift
Lift an insight through DREDGE pipeline
Request Body: 
{
  "insight_text": "Digital memory must be human-reachable"
}
Response: 
{
  "status": "lifted",
  "insight": "...",
  "lifted_insight": "[Enhanced] ...",
  "confidence_score": 0.89,
  "models_applied": ["quasimoto_4d", "string_theory_10d"]
}
GET/insights/history
Get lifted insight history

4. Swift Toolchain NEW

POST/swift/build
Build Swift CLI
Request Body: 
{
  "optimization": "-O"
}
POST/swift/run
Run Swift package
Request Body: 
{
  "args": ["--version"]
}
POST/swift/tests
Run Swift tests
POST/swift/ios-build
Build iOS MVP app

5. Dependabot Alerts NEW

GET/dependabot/alerts
Fetch GitHub Dependabot alerts
GET/dependabot/alerts/{id}/explain
Get AI-powered alert explanation
POST/dependabot/alerts/{id}/dismiss
Dismiss an alert
Request Body: 
{
  "reason": "not_used",
  "comment": "..."
}

6. API Endpoint Tester NEW

GET/api-tester/endpoints
List all DREDGE API endpoints
POST/api-tester/test
Test an API endpoint
Request Body: 
{
  "method": "GET",
  "endpoint": "/health"
}

7. Container Status Monitor NEW

GET/containers/status
Get status of running containers
Response: 
{
  "containers": [
    {
      "name": "dredge-flask",
      "port": 3001,
      "status": "running",
      "cpu_percent": 0.5,
      "memory_mb": 256.32
    }
  ]
}
GET/containers/{name}/logs
Stream container logs

8-9. Visualization NEW

POST/visualization/string-spectrum
Compute string theory vibrational spectrum
Request Body: 
{
  "max_modes": 10,
  "dimensions": 10
}
POST/visualization/wave-function
Generate wave function plot data
Request Body: 
{
  "model": "quasimoto_1d",
  "parameters": { }
}

10. Code Generation NEW

GET/codegen/templates
List code generation templates
POST/codegen/generate
Generate code from template
Request Body: 
{
  "template": "swift_cli",
  "config": { }
}

Examples

cURL Examples

List Models: 
curl http://127.0.0.1:8000/api/advanced/models/list
Load Model: 
curl -X POST http://127.0.0.1:8000/api/advanced/models/load \
  -H "Content-Type: application/json" \
  -d '{"model_id":"quasimoto_4d"}'
Lift Insight: 
curl -X POST http://127.0.0.1:8000/api/advanced/insights/lift \
  -H "Content-Type: application/json" \
  -d '{"insight_text":"Your insight"}'

Python Examples

List Models: 
import requests
r = requests.get('http://127.0.0.1:8000/api/advanced/models/list')
print(r.json())

JavaScript Examples

List Models: 
fetch('http://127.0.0.1:8000/api/advanced/models/list')
  .then(r => r.json())
  .then(d => console.log(d))

Response Status Codes

Code Meaning
200 Success
400 Bad Request
404 Not Found
500 Server Error

Rate Limiting

No rate limiting applied. Recommended:

  • Max 1000 requests/minute per IP
  • Max 100 concurrent connections
  • Implement request queuing for production
